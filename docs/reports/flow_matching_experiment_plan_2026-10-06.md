# Flow Matching 与竞争方法实验计划

计划版本：v1，2026-10-06。执行配置以 `configs/reproducibility/flow_matching_campaign.v1.json` 为准。

用户授权范围：检查和修正作者代码、预处理原论文与新增数据、训练和评估、比较原文结果与跨数据集效果。代码修正只作用于独立工作副本，原始下载和作者源文件保留。

## 实验目标与判定

| 阶段 | 目标 | 交付与判定 |
|---|---|---|
| A：作者原协议 | 在论文指定数据、版本、划分、预算与指标上运行作者实现 | 逐表记录论文均值/标准误、本地各次结果、均值/标准误、差值、配置和代码差异。未跑全重复次数不判定完成；不从多次测试结果挑选最接近论文的一次 |
| B：修正后协议 | 检查错误、数据泄漏、选模与指标实现 | 保留原流程复现与修正版两条记录；修正后的分数下降同样如实报告。修正版改变了协议时，不标为原表精确复现 |
| C：新增数据迁移 | 检查方法的误差、效率、优势和鲁棒性是否保持 | 在统一数据划分、缺失掩码、调参预算和指标下重训。跨数据集绝对指标没有同值要求；比较优势方向与配对差值的不确定性 |

“与论文一致”先要求协议匹配，再比较数值。第一波采用论文舍入精度和论文/本地标准误构造预先登记的数值兼容区间；此筛查不等于证明统计等效。参考值缺失、样本数变化、诊断小样本、划分不明、原版数据未取得的实验标为不可直接比较。

新增数据上的共同协议为 `transfer_ensemble_v1`：样本中位数计算 MAE、样本均值计算 RMSE、经验分布精确 CRPS，追加 90% 区间覆盖率和区间宽度；所有指标只评价人工隐藏的真实观测。原 CSDI 使用 19 分位数近似 CRPS、Torch 中位数点预测，CFMI 使用经验 CRPS、NumPy 中位数 MAE 与均值 RMSE，原表复现各自保留，不能混用。推理时间先记录作者原批量的实际耗时；跨方法速度结论另需同一硬件、相同样本数与批量的独立计时，不能直接比较当前不同默认批量的耗时。图像生成、序列生成、预测与异常检测按各自原论文任务和指标评估，不混成一张填补排行榜。

迁移至少使用五个固定训练/缺失掩码种子。方法间采用配对种子和掩码；先报告所有种子的均值、标准误与差值，再判断优势保持、反转或证据不足。种子区间反映训练与掩码变化，不冒充跨独立工业站点的统计证据。必要时按患者、仿真 Run 或试验文件做分组重采样。

## 数据处理规则与新增数据

1. 原始下载目录只读使用，处理结果存入 `processed_campaign_v1`；每个处理包记录原始来源、规则、特征顺序、分组、划分/掩码哈希与实际缺失率。
2. 只在原本有真实观测的位置生成评估掩码；原生缺失值不作为真值。时间戳、异常标签、故障编号、报警标签等不作为填补模型输入。
3. 原协议保留作者的标准化与 RNG，相关缺陷显式标注；修正版/迁移协议只用训练集拟合标准化、填充值和图结构。先切分患者/运行/试验，再生成窗口。
4. 新增缺失模式为点缺失、连续块缺失、整通道缺失，目标比例为 10%、50%、90%；由于通道/时长离散性，保存实际比例。
5. 首批工业迁移为 TEP DTU v1、SKAB、PRONTO 的连续过程变量。后续加入 ETT、电力、交通数据中该方法未使用过的部分。明确区分同域新数据、跨领域重训与冻结模型零样本测试；不把重新训练称为零样本迁移。

TEP 首批配置为六模式、故障 1/2/4/8/12、强度 100、Run 1–50，每轨迹均匀取五个长度 48 的窗口；不同条件的相同 Run 保守地视为同一组。未完成/不存在的轨迹单列记录，不隐式替换。此计算可行的预登记子集用于新 benchmark，不能称为化工 FM 论文的原子集或全部 TEP 数据。

已准备的 TEP 包包含 7,230 个窗口、53 个过程/操纵变量；训练/验证/测试窗口数为 5,055/725/1,450，三者 Run 组无交叉。对应五个掩码种子 × 三模式 × 三比例，共 45 个处理包。完整六个原始 HDF5 均保留。

SKAB 已准备 952 个长度 48、8 特征的窗口，整试验文件划分为训练/验证/测试 709/91/152 个窗口。PRONTO 已准备 944 个长度 48、17 特征的窗口，按 Testday2/3/4 分为 258/443/243 个窗口。每套工业数据有 45 个掩码包，标准化参数仅由训练集拟合，时间和标签列已排除。

第一批迁移配置已冻结为 270 个评估任务：两方法 × 三数据集 × 五种子 × 三模式 × 三缺失比例。共有 30 次完整训练，其余评估复用同方法/数据集/种子的最终轮检查点；统一使用原方法固定超参数，不在测试集调参。配对报告检查数据哈希、测试例数和评估点数一致，全部五个种子完成后报告配对差值及 95% 区间；多数据集多指标的区间作为探索性证据，不声称已控制多重比较。

迁移门禁要求第一批 30 个 PhysioNet 任务全部完成，且全部原论文实验范围已完成或具体记录材料不可获得。当前 `original_scope_status=in_progress`，Air-36 和其他原论文实验尚未全部完成，迁移队列会等待，不会因只跑完 PhysioNet 就跳过剩余原实验。

PhysioNet 已从原始 tar 重建 4,000 名患者 × 48 小时 × 35 特征，与真实作者 LFS 包的观测数组/原始掩码逐值一致。CFMI 与 CSDI 使用不同 RNG 划分，原表复现分别遵循各自实现；人工评估掩码也分别按各作者实现生成，统一掩码只用于共同协议。预处理目录中 `cfmi_author` 掩码包的 legacy point mask 仅供诊断，CFMI 原表队列实际使用作者 Torch 缺失生成器。

Air-36 已从作者 STMVL 包准备五个验证月份版本。公开原文件为 8,759 × 36，从 2014-05-01 01:00 起，保留此数据而不补写论文概述中的 8,760 行。每次测试为 82 个窗口，两处尾窗各截去前 12 个重复时刻。CSDI 第一版本训练/验证/测试窗口数为 4,842/709/82；保持作者历史掩码和混合训练策略。作者标准化含非测试月份的验证数据，保留并标注此处原协议特点；迁移仍只由训练集拟合。CSDI 原文未列出五次运行具体选中的验证月份，采用预登记的前五个索引并明确该不确定性，当前比较程序不会将其标为精确原表复现。

- CFMI：在作者声明的 Lightning 2.2.0 下，`pl.Any` 导入失败，已改为 `typing.Any`；增加可选检查点恢复，不改模型数学定义。四套真实数据的 CPU 单批训练和两例/两样本采样预检通过；预检指标仅检查流程。稀疏数据的逐坐标 CRPS 对无评估点坐标返回 NaN，按作者 `nanmean` 汇总并记录未定义坐标数，不掩盖无穷值或其他指标的 NaN。Air-36 评估张量为 `[样本,时间,特征]`，当前公开代码沿特征轴截断尾窗重复部分；同一次采样分别保存原程序指标与沿时间轴修正的 `corrected_metrics`，不将修正分数混入原表比较。
