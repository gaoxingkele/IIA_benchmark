# Semantic gene bank

This bank records reusable WHERE × WHY lessons. It is not a leaderboard and it
does not convert a failed gate into method credit.

| Gene | WHERE (activation context) | WHY (causal rationale) | Evidence | Decision |
|---|---|---|---|---|
| IIA-G001 event-fingerprint payload | CTFH/HDAM and related flood classifiers require sparse alarm activations, within-flood event order, and class-aligned episodes. | Persistent process-state windows suppress newly appearing events and destroy discriminative hashes/templates. | PRONTO CTFH has zero consensus hashes in all four classes; HDAM balanced accuracy is 0.1010. | Reuse TEP Alarm/FCC/NPP event adapters; keep PRONTO only as an M1 mismatch sentinel. |
| IIA-G002 coverage needs efficiency | Conformal AFC results are meaningful only when coverage is paired with set size, singleton rate, and prefix behavior. | A prediction set containing every class obtains coverage 1.0 without resolving uncertainty. | PRONTO ConE and Cross-Conformal have coverage 1.0, set size 4.0, singleton rate 0.0 at every prefix. | G1 fails if set-size efficiency is degenerate, even when coverage passes. |
| IIA-G003 task-level match precedes tuning | Apply before any algorithm/dataset sweep. | Hyperparameter search cannot repair absent labels, incompatible event semantics, or leakage across windows from one run. | Current T4 proxy failures and zero leaderboard-eligible splits. | Require M2/M3 admission and G0 before tuning; M1 receives diagnostic-only credit. |
| IIA-G004 retain state/edge representation pairs | Alarm-state datasets used by event-fingerprint or template methods. | State duration can carry class information even when the method narrative emphasizes new activations; edge conversion may discard discriminative persistence. | FCC CTFH state BA 0.5125 versus rising-edge BA 0.3656 on the same complete-run split. | Register state versus rising-edge as a paired ablation; do not force one representation globally. |
| IIA-G005 task-matched data can reverse apparent method failure | Apply when a method fails G1 on a representation-mismatched proxy but passes data integrity checks. | A negative proxy result may diagnose absent event/template structure rather than broken code. | HDAM rises from PRONTO BA 0.1010 to FCC BA 0.99375; CTFH moves from zero to 62 consensus hashes. | Keep both results, re-test on a second task-matched dataset, and deny paper-score credit until P2/P3 closure. |
| IIA-G006 enumerate closures, not every frequent subset | Dense alarm transactions with CHARM/closed-pattern mining. | Generating all frequent subsets before closure filtering pays exponential cost for patterns that must later be discarded; each distinct vertical TID intersection already determines one closure. | Parent exceeded 4 min and 754 MB observed memory; direct TID-closure enumeration finished the unchanged FCC run in 1.54 s and passed a brute-force equivalence test. | Replace the runtime cell while preserving the frozen mathematical output; retain the failed parent record. |
| IIA-G007 representation effects are dataset-dependent | CTFH-style fingerprints on complete alarm-state episodes. | Persistent duration can dominate in FCC, while the longer TEP payload retains sufficient transition structure for edges to remove nuisance persistence. | FCC state/edge BA is 0.5125/0.3656, whereas TEP state/edge is 0.7250/0.7500 on paired splits. | Always register state/edge as a paired ablation; a representation winner on one plant is not a universal default. |
| IIA-G008 bind HDAM template width to episode support | HDAM inputs whose binned duration is much longer than the source lane. | Short template search scales with source candidates × peer episodes × peer placements; full-duration templates collapse placements without changing the registered cosine-matching definition. | TEP 12/60-bin parent was stopped at 482.6 s before prediction; full 60-bin template completed in 9.67 s. | Select width from input/support and runtime before test prediction; retain the parent failure and grant runtime-only repair credit. |
| IIA-G009 conformal coverage must be read with calibration efficiency | Uncertainty-aware AFC on task-matched labelled episodes. | Split conformal can produce highly efficient sets with finite-sample undercoverage; cross-conformal pooling can restore coverage at a set-size cost that depends on the label space. | Three-seed full-prefix ConE coverage/set size is 0.8167/1.0050, 0.7689/1.0871, and 0.9010/6.6745 on TEP/NPP/FCC; Cross-Conformal raises coverage to 0.9617/0.9735/0.9661 with sizes 1.2467/1.5606/8.0703. | Report coverage, set size, empty/singleton rates and prefix curves together; do not rank by coverage alone. Falsify with a grouped calibration protocol where the coverage gain disappears or requires the full label space. |
| IIA-G010 group threshold variants and duplicate trajectories | NPP-style simulators expose many alarm-threshold slices derived from the same underlying run identities. | Randomly splitting threshold variants or exact state/edge duplicates leaks the same simulated trajectory into train and test; cross-label duplicates also make labels non-identifiable. | NPP has 101 alpha layers; the alpha-0.50 G0 found 180 within-class state duplicates, 19 state-or-edge cross-label components containing 45 runs, and one identical MD state trajectory across 100 runs. The retained 528-run split has zero state/edge components crossing partitions. | Freeze one representative per state-or-edge component, remove cross-label conflicts, and group the same base run across alpha sweeps; falsify by asserting zero component overlap in every split. |
| IIA-G011 separate causal structure from root-tag accuracy | NTE/NDTE on datasets with fault-family labels but no alarm-tag causal truth. | A class label can group graph-stability comparisons, but it cannot identify which alarm variable is the physical root; converting the class into a tag target invents ground truth. | FCC/TEP/NPP NTE activates on 30/32, 10/10, and 22/22 episodes, and within-class edge Jaccard exceeds cross-class on all three, while none exposes a root-alarm tag. | Credit surrogate-significant graph recovery, NDTE pruning, lags, and stability; prohibit top-k/MRR until tag-level causal truth exists. Falsify with a dataset that supplies an independently annotated root tag. |
| IIA-G012 temporal contribution requires a varying cause signal | PLR lag and non-negative contribution analysis on process episodes. | A run-level constant disturbance has zero within-episode trend and undefined temporal lag, even when its column name correctly identifies the injected scenario. | All 1,600 FCC runs contain the mapped root-disturbance column, but 0/1,600 root columns and 0/1,600 disturbance matrices vary within a run. | Downgrade FCC×PLR to M1/P0 and retain the G0 denial; require time-varying candidate causes before scoring lag or contribution. Falsify by observing nonzero within-run root-driver variation above tolerance. |
| IIA-G013 equation reproduction is not acquired-data validation | Published numerical systems whose equations, noise law, delays, and evaluation segments are fully specified. | An equation-defined run can close mathematical invariants and seed robustness, but it cannot establish plant transfer or receive E2/E3 credit without an acquired payload. | Chapter 4.4 PLR recovers delays 10/8 and all 32 dominant drivers for seeds 41/42/43, while the thermal-plant data remain unavailable. | Credit P2 numerical reproduction at E1; require an independently acquired M2/M3 dataset before promotion to E2. Falsify by supplying the cited industrial payload and its frozen labels. |
| IIA-G014 smoothing must report transition cost with nuisance gain | Recursive alarm-state filters evaluated against instantaneous state lookup. | Persistence rejects short false/missing alarms by delaying state changes, so whole-stream point accuracy can fall even when nuisance robustness improves sharply. | Chapter 4.3 recreation gives nuisance accuracy 0.8627 versus 0.0588, but overall accuracy 0.9491 versus 0.9850 and 19-sample transition delays. | Report nuisance-slice accuracy, stable-state accuracy, and detection delay alongside overall accuracy; do not call smoothing universally superior. Falsify with paired data where nuisance gain vanishes or transition delay exceeds the frozen bound. |
| IIA-G015 direct-TE requires an activated mediation triangle | IGDTE or conditional-TE pruning after an IGTE screening graph. | A directness test can only remove an indirect edge when the screened graph contains a source-target edge plus a viable intermediate path; zero pruning does not prove that every retained edge is direct. | Chapter 4.2 yields no IGDTE-pruned edge in 21 episode-by-seed evaluations; the sparse screened graphs contain no activated mediation triangle. | Fail the IGDTE activation gate and deny direct-causality credit. Falsify with a registered delayed-chain control or acquired graph containing an IGTE-significant triangle that IGDTE prunes. |
| IIA-G016 root rank cannot substitute for graph recovery | Continuous-variable causal discovery with a published root and reference edge table. | A high marginal outgoing score may rank the expected root even when the recovered adjacency is structurally wrong; root rank and edge recovery test different claims. | On TEP IDV(1), V1 ranks second while both IGTE and IGDTE reference-edge F1 are 0 for all three seeds. | Report rank and edge metrics separately and fail G4 when the named table does not match. Falsify by recovering the reference edges within the frozen tolerance, not by rank alone. |
| IIA-G017 on/off delay symmetry is part of the algorithm | Book Chapter 2 delay timers whose Markov chain has n no-alarm and n alarm states. | Requiring n samples to activate but only one to clear changes the stationary MAR/FAR and cannot reproduce the published chain. | The one-sided parent produced Xu Example 2 MAR error about 0.39; the symmetric state machine reduces all three-seed Example 2 FAR/MAR errors below 0.005. | Bind analytical equations and empirical state machine to the same on/off semantics. Falsify with n>1 sequences containing isolated clear samples. |
| IIA-G018 execution is not mechanism activation | Methods with explicit data prerequisites such as duration PMFs, mediation triangles, or a deadband suitability index. | A fallback can keep outputs finite while the defining statistic is unidentifiable or its applicability test fails. | Chapter 2 non-IID uses zero-event fallback in 19/27 units; deadband's 45-degree gate passes in 7/27. All units execute, but only eligible units activate. | Record execution and activation separately; fallback/counterfactual metrics cannot promote the evidence tier. Falsify by acquiring episodes with both nuisance-duration types or a positive suitability interval. |
| IIA-G019 calibration targets require held-out stationarity checks | Threshold/delay/deadband/APP designs transferred from calibration to later process operation. | A design can optimize nominal FAR/MAR targets on calibration yet fail after operating-regime drift or when system fault labels do not equal per-variable alarm truth. | TEP IID FAR is 0.0067, while PRONTO IID MAR is 0.7905 and SKAB IID FAR is 0.5949; APP similarly misses targets across all three. | Always report held-out FAR and MAR beside design loss and label semantics; deny target-satisfaction claims on transferred system labels. Falsify with expert alarm truth and stationary independent runs. |
| IIA-G020 normal-zone transfer requires a normal-regime drift audit | Convex, search-cone, covariance, or other NOZ monitors trained on one normal block and evaluated on another. | A geometric boundary cannot distinguish faults from a shifted but legitimate operating regime; high detection with near-unit FAR is boundary drift, not useful sensitivity. | SKAB normal train/evaluation median KS is 0.4635, maximum KS 0.9581, and maximum standardized median shift 2.2467; convex/search-cone FAR is 0.9744/0.9862. | Report independent-normal drift before NOZ scores and deny deployment credit under severe drift. Falsify on a stationary normal split or with a pre-registered regime-adaptation method. |
| IIA-G021 physical-model activation requires named variables and units | Physics-guided monitors whose equations refer to pressure, flow, temperature, geometry, or material constants. | Relabeling arbitrary sensor columns as physical inputs can produce finite residuals while violating dimensional meaning and operational constraints. | TEP/PRONTO/SKAB lack a verified Pc/Dc/T1/T2 mapping; only Table 3.5 equation-defined condenser samples activate, with fit above 0.99998. | Deny real-data activation unless identities, units, and constraints are documented; synthetic equation checks receive synthetic-only credit. Falsify with an acquired condenser payload and unit audit. |
| IIA-G022 source arithmetic is itself a reproducibility gate | Named tables used to freeze tuning choices or target values. | A printed arithmetic error can silently change an optimizer or cause an exact-check failure if the reported result is trusted over its operands. | Book Table 3.4 prints 0.3216-0.1225=0.1902; direct subtraction is 0.1991, while the eligible optimum kp=0.84 remains unchanged. | Store operands, reported value, calculated value, and discrepancy separately; freeze selections from declared rules rather than silently correcting the source. Falsify against an erratum or source code. |
| IIA-G023 physical fit does not close geometric alarm performance | Physics-guided NOZ systems that first fit a process model and then construct a geometric operating zone. | A high regression goodness only verifies the physical mapping; sparse cone coverage, angle selection, and model uncertainty can still create excessive alarms. | Chapter 3.4 equation samples give physical fit 0.9999883 and F1 0.8694, yet the mean 99% FAR upper bound is 0.3500 versus the book target near 0.075. | Gate physical fit, zone coverage, FAR/MAR posterior bounds, and ensemble robustness separately. Falsify by meeting Eq. 3.130 with a frozen dense grid and independent parameter ensembles. |
| IIA-G024 hash complete trajectories before grouped splitting | Repeated simulator runs or threshold variants used for alarm-sequence classification. | A run identifier is not an independent sample when two full alarm trajectories are identical; cross-partition duplicates inflate nearest-template scores. | FCC contains 27 duplicate nonrepresentatives and 24 duplicate runs crossing the old fixed split; grouped-unique alignment BA falls from 0.8875 to a three-seed mean 0.7736. | Group or deduplicate exact state/edge components before splitting and assert zero signature overlap. Falsify by showing the score is stable under a grouped-unique split. |
| IIA-G025 mechanism, performance, and competition are separate gates | Any algorithm that can emit nonconstant predictions without meeting an effectiveness target or beating a simple control. | Executable/nondegenerate output establishes mechanism only; it does not establish useful accuracy or incremental value. | Chapter 5 alignment activates mechanically but loses to set Jaccard in 9/9 dataset-seeds; maximum entropy is nonuniform but fails the 0.8 eta gate in 9/9. | Report three gates independently and deny competitive credit unless a frozen baseline is exceeded. Falsify with paired grouped seeds showing a consistent positive margin. |
| IIA-G026 pattern compression is not automatically classification gain | Closed-pattern mining evaluated through a downstream class label. | A representative pattern may organize and compress alarm groups without improving class prediction over a simple class-core set. | CHARM balanced accuracy is 0.9667/0.7182/0.9347 on TEP/NPP/FCC but exactly matches the class-core Jaccard control in every seed. | Credit closedness and compression separately; deny classifier-superiority claims. Falsify with held-out labels where mined representatives beat the frozen core-set baseline. |
| IIA-G027 SOTA representation rankings are plant-dependent | Alarm-flood classifiers compared on grouped complete trajectories from different simulators. | A representation that is almost perfect on one plant may discard the discriminative structure of another; paper recency or neural complexity is not a transferable ranking rule. | CASIM BA is 1.0000/0.8182/0.9922 on TEP/NPP/FCC; CTFH is strongest relative to the parent only on NPP at 0.8371; modified TF-IDF is 0.8450/0.6250/0.9896; the time histogram falls to 0.2652/0.3698 on NPP/FCC. | Require the same grouped multi-dataset split, a simple class-core parent, and seed variation before crediting a default model. Falsify with an externally acquired plant where one representation wins the paired gate consistently. |
| IIA-G028 point-error gain does not guarantee calibrated timing intervals | Forecasting the next reduction of an online conformal prediction set. | A regressor can reduce mean timing error while its jackknife+ interval still misses the nominal coverage target on one domain. | Mean MAE versus the median-time parent is 12.5743/16.0377, 3.7065/4.0506, and 0.8197/2.3580 minutes on TEP/NPP/FCC; interval coverage is 0.9032/0.8666/0.9230, so NPP passes only 2/3 seed-level coverage gates. | Gate timing error, interval coverage, width, and delay-timer activation separately. Falsify with a sealed NPP split that reaches nominal coverage without erasing the MAE advantage. |
| IIA-G029 clean accuracy and corruption robustness are distinct rankings | AFC methods exposed to missing, spurious, timing, detector-delay, and mixed test-only corruptions. | A high clean balanced accuracy does not determine the area under a severity curve, especially when the representation depends on exact event timing or sparse hashes. | FCC modified TF-IDF has clean BA 0.9896 but robustness AUC 0.7151; CTFH has 0.3828/0.2922, while CASIM has 0.9922/0.8318. TEP HDAM retains AUC 1.0000. | Publish clean score, per-corruption AUC, maximum degradation, and paired robustness credit separately. Falsify when clean and robustness rankings agree across all grouped seeds and perturbation families. |
