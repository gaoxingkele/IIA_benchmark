# Semantic gene bank

This bank records reusable WHERE × WHY lessons. It is not a leaderboard and it
does not convert a failed gate into method credit.

| Gene | WHERE (activation context) | WHY (causal rationale) | Evidence | Decision |
|---|---|---|---|---|
| IIA-G001 event-fingerprint payload | CTFH/HDAM and related flood classifiers require sparse alarm activations, within-flood event order, and class-aligned episodes. | Persistent process-state windows suppress newly appearing events and destroy discriminative hashes/templates. | PRONTO CTFH has zero consensus hashes in all four classes; HDAM balanced accuracy is 0.1010. | Reuse TEP Alarm/FCC/NPP event adapters; keep PRONTO only as an M1 mismatch sentinel. |
| IIA-G002 coverage needs efficiency | Conformal AFC results are meaningful only when coverage is paired with set size, singleton rate, and prefix behavior. | A prediction set containing every class obtains coverage 1.0 without resolving uncertainty. | PRONTO ConE and Cross-Conformal have coverage 1.0, set size 4.0, singleton rate 0.0 at every prefix. | G1 fails if set-size efficiency is degenerate, even when coverage passes. |
| IIA-G003 task-level match precedes tuning | Apply before any algorithm/dataset sweep. | Hyperparameter search cannot repair absent labels, incompatible event semantics, or leakage across windows from one run. | Current T4 proxy failures and zero leaderboard-eligible splits. | Require M2/M3 admission and G0 before tuning; M1 receives diagnostic-only credit. |
| IIA-G004 retain state/edge representation pairs | Alarm-state datasets used by event-fingerprint or template methods. | State duration can carry class information even when the method narrative emphasizes new activations; edge conversion may discard discriminative persistence. | FCC CTFH state BA 0.5125 versus rising-edge BA 0.3656 on the same complete-run split. | Register state versus rising-edge as a paired ablation; do not force one representation globally. |
| IIA-G005 task-matched data can reverse apparent method failure | Apply when a method fails G1 on a representation-mismatched proxy but passes data integrity checks. | A negative proxy result may diagnose absent event/template structure rather than broken code. | HDAM rises from PRONTO BA 0.1010 to FCC BA 0.99375; CTFH moves from zero to 62 consensus hashes. | Keep both results, re-test on a second task-matched dataset, and deny paper-score credit until P2/P3 closure. |
| IIA-G006 enumerate closures, not every frequent subset | Dense alarm transactions with CHARM/closed-pattern mining. | Generating all frequent subsets before closure filtering pays exponential cost for patterns that must later be discarded; each distinct vertical TID intersection already determines one closure. | Parent exceeded 4 min and 754 MB observed memory; direct TID-closure enumeration finished the unchanged FCC run in 1.54 s and passed a brute-force equivalence test. | Replace the runtime cell while preserving the frozen mathematical output; retain the failed parent record. |
| IIA-G007 representation effects are dataset-dependent | CTFH-style fingerprints on complete alarm-state episodes. | Persistent duration can dominate in FCC, while the longer TEP payload retains sufficient transition structure for edges to remove nuisance persistence. | FCC state/edge BA is 0.5125/0.3656, whereas TEP state/edge is 0.7250/0.7500 on paired splits. | Always register state/edge as a paired ablation; a representation winner on one plant is not a universal default. |
| IIA-G008 bind HDAM template width to episode support | HDAM inputs whose binned duration is much longer than the source lane. | Short template search scales with source candidates × peer episodes × peer placements; full-duration templates collapse placements without changing the registered cosine-matching definition. | TEP 12/60-bin parent was stopped at 482.6 s before prediction; full 60-bin template completed in 9.67 s. | Select width from input/support and runtime before test prediction; retain the parent failure and grant runtime-only repair credit. |
| IIA-G009 conformal coverage must be read with calibration efficiency | Uncertainty-aware AFC on task-matched labelled episodes. | Split conformal can produce highly efficient sets with finite-sample undercoverage; cross-conformal pooling can restore coverage at a modest set-size cost. | TEP ConE: coverage 0.89/set 1.08; Cross: coverage 0.965/set 1.26. Both have singleton rate about 0.73-0.74. | Report coverage, set size, empty/singleton rates and prefix curves together; do not rank by coverage alone. |
| IIA-G010 group threshold variants and duplicate trajectories | NPP-style simulators expose many alarm-threshold slices derived from the same underlying run identities. | Randomly splitting threshold variants or exact state/edge duplicates leaks the same simulated trajectory into train and test; cross-label duplicates also make labels non-identifiable. | NPP has 101 alpha layers; the alpha-0.50 G0 found 180 within-class state duplicates, 19 state-or-edge cross-label components containing 45 runs, and one identical MD state trajectory across 100 runs. The retained 528-run split has zero state/edge components crossing partitions. | Freeze one representative per state-or-edge component, remove cross-label conflicts, and group the same base run across alpha sweeps; falsify by asserting zero component overlap in every split. |
| IIA-G011 separate causal structure from root-tag accuracy | NTE/NDTE on datasets with fault-family labels but no alarm-tag causal truth. | A class label can group graph-stability comparisons, but it cannot identify which alarm variable is the physical root; converting the class into a tag target invents ground truth. | FCC/TEP/NPP NTE activates on 30/32, 10/10, and 22/22 episodes, and within-class edge Jaccard exceeds cross-class on all three, while none exposes a root-alarm tag. | Credit surrogate-significant graph recovery, NDTE pruning, lags, and stability; prohibit top-k/MRR until tag-level causal truth exists. Falsify with a dataset that supplies an independently annotated root tag. |
| IIA-G012 temporal contribution requires a varying cause signal | PLR lag and non-negative contribution analysis on process episodes. | A run-level constant disturbance has zero within-episode trend and undefined temporal lag, even when its column name correctly identifies the injected scenario. | All 1,600 FCC runs contain the mapped root-disturbance column, but 0/1,600 root columns and 0/1,600 disturbance matrices vary within a run. | Downgrade FCC×PLR to M1/P0 and retain the G0 denial; require time-varying candidate causes before scoring lag or contribution. Falsify by observing nonzero within-run root-driver variation above tolerance. |
| IIA-G013 equation reproduction is not acquired-data validation | Published numerical systems whose equations, noise law, delays, and evaluation segments are fully specified. | An equation-defined run can close mathematical invariants and seed robustness, but it cannot establish plant transfer or receive E2/E3 credit without an acquired payload. | Chapter 4.4 PLR recovers delays 10/8 and all 32 dominant drivers for seeds 41/42/43, while the thermal-plant data remain unavailable. | Credit P2 numerical reproduction at E1; require an independently acquired M2/M3 dataset before promotion to E2. Falsify by supplying the cited industrial payload and its frozen labels. |
| IIA-G014 smoothing must report transition cost with nuisance gain | Recursive alarm-state filters evaluated against instantaneous state lookup. | Persistence rejects short false/missing alarms by delaying state changes, so whole-stream point accuracy can fall even when nuisance robustness improves sharply. | Chapter 4.3 recreation gives nuisance accuracy 0.8627 versus 0.0588, but overall accuracy 0.9491 versus 0.9850 and 19-sample transition delays. | Report nuisance-slice accuracy, stable-state accuracy, and detection delay alongside overall accuracy; do not call smoothing universally superior. Falsify with paired data where nuisance gain vanishes or transition delay exceeds the frozen bound. |
| IIA-G015 direct-TE requires an activated mediation triangle | IGDTE or conditional-TE pruning after an IGTE screening graph. | A directness test can only remove an indirect edge when the screened graph contains a source-target edge plus a viable intermediate path; zero pruning does not prove that every retained edge is direct. | Chapter 4.2 yields no IGDTE-pruned edge in 21 episode-by-seed evaluations; the sparse screened graphs contain no activated mediation triangle. | Fail the IGDTE activation gate and deny direct-causality credit. Falsify with a registered delayed-chain control or acquired graph containing an IGTE-significant triangle that IGDTE prunes. |
| IIA-G016 root rank cannot substitute for graph recovery | Continuous-variable causal discovery with a published root and reference edge table. | A high marginal outgoing score may rank the expected root even when the recovered adjacency is structurally wrong; root rank and edge recovery test different claims. | On TEP IDV(1), V1 ranks second while both IGTE and IGDTE reference-edge F1 are 0 for all three seeds. | Report rank and edge metrics separately and fail G4 when the named table does not match. Falsify by recovering the reference edges within the frozen tolerance, not by rank alone. |
