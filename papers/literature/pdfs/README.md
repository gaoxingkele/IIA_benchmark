# Literature PDF policy

PDFs in this directory are local acquisition artifacts by default and remain
ignored by Git. `papers/literature/download_manifest.json` records provenance,
checksum, page count, acquisition method, license, and redistribution status.

Only unmodified papers with an explicit license that permits redistribution are
tracked. The current tracked set is:

| File | License | Source |
| --- | --- | --- |
| `zhang2022_igte.pdf` | CC BY 4.0 | <https://doi.org/10.3390/e24020212> |
| `faulwasser2024_casim.pdf` | CC BY 4.0 | <https://doi.org/10.1017/dce.2024.22> |
| `faulwasser2024_cone_afc.pdf` | CC BY 4.0 | <https://doi.org/10.1109/ACCESS.2024.3492348> |
| `faulwasser2025_uncertainty_reduction.pdf` | CC BY-NC-ND 4.0 | <https://doi.org/10.1016/j.ifacol.2025.11.935> |

Subscription copies, publisher-restricted PDFs, authenticated ResearchGate
copies, and public preprints without an explicit redistribution license must not
be force-added. They remain local-only or use an approved controlled channel.
