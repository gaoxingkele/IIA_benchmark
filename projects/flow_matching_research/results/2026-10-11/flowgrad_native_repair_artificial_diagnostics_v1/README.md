# FlowGrad 原始/修复分支的完整数学诊断

本轮完成三个显式修复，并实际执行27组128×128人工图像诊断及全部27组独立闭式解复算。**这些是公式与数值验证，不是原数据集性能；完整论文异常检测实验仍未完成。**

- 原始FlowGrad的首步直线度会用Python负索引把末步作为前邻居；修复为不存在前邻居时贡献0。
- 速度能量为0时原始相对比值可能出现0/0；修复为相同速度距离0，不同速度的相对距离无限大并强制分段。没有引入未经说明的eps。
- 本地v1初始噪声适配器会以图像dtype重算VJP时间，可能与原始float32前向时间不同；修复为使用逐次保存的原始前向时间张量。此项属于本地适配器的问题，不归咎于作者源码。

原始作者源码、本地v1适配器和先前所有冻结依赖保持字节一致。新分支捕获原有前向调用，没有增加模型前向次数；27组诊断中，每个完整前向状态均逐位匹配原始分支。修复仅用于明确登记的本地分支，不代表未公开的作者异常检测适配。

测试初次发现本地修复加载器遗漏类型注解依赖，修正后17项测试全部通过。随后使用成对保存的 `[1,3,128,128]` float64人工图像，比较零场、自治线性场、时变线性场，在7/10/100步及0/0.005/0.01阈值下的全部27组梯度。每组先对照完整自动微分，再以不使用自动微分/VJP求期望导数的仿射乘积闭式解独立复算，全部通过。

修复并不保证近似梯度更好。在时变线性场7步/完整分段设置下，原始梯度相对误差约 `1.72e-8`，修复约 `1.01e-11`；但100步/阈值0.01设置下，原始误差约 `0.198829`，修复约 `0.200690`，即该近似案例略微变差。全部结果保留在CSV，未筛掉不利设置。完整分段修复均通过原有 `1e-9` 相对误差门限；近似分段不作“必然改善”的保证。

上述误差不可换算成异常F1/AUC，也不能据此声称论文效果虚高或修复提升检测性能。必须在同一完整真实图像模型检查点、成对噪声、同样原始计算预算和评估协议下做原始/修复比较；这些义务继续保留，未降低2000epoch训练预算或更改既有资源门限。
