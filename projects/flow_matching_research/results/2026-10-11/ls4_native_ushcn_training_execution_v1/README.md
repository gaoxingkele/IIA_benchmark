# USHCN 完整原生训练与 GRASP τ=0.25 新结果

USHCN 的完整原生训练代码和队列已接入并启动，当前等待既定 GPU 资源门槛。尚无该队列的 500 轮完整训练分数。本轮另核验了新完成的 GRASP τ=0.25 原始实验，并将其实际指标纳入新的完整结果表。

实际调用下载的 `train_interp_extrap.main/train/eval`、原 VAE、原优化器和调度器。先对两个分支、五折、两种配置的全部 **20 个容量案例**分别训练一个完整 epoch、评估全部测试序列，然后执行全部 100 个完整任务。容量案例是诊断，不作为 500 轮实验结果。

作者 CLI 默认训练种子为 42，原 YAML 默认 fold 0；其他四个训练种子和 folds 1–4 明确属于本地鲁棒性扩展。五个数据折重复使用同一批原始序列，不能将跨折的 25 次运行称为 25 个独立种子，也不能混合两个划分分支计算一个性能均值。

代码对完整批次及最后不足 64 的批次、500 个实际训练 epoch、每次优化器更新、全部测试评估和产物哈希作观察核验。保存最终训练状态、优化器／调度器／RNG，以及实际最佳与最终评估模型的**评估前 RNG 和权重**，用于后续独立重推断。原测试 MSE 检查点选择行为保留，未将其改称严格验证集选择。

官方共轭 Cauchy 修正在运行时单独应用，原源码未改写。原始数据、原样划分缺陷、ID 修正分支、验证／测试过滤、训练加验证前缀归一化、未使用的未来观测，以及插值输入／目标重合均保留并披露。完整数据与协议证据见[前一轮报告](../ls4_ushcn_and_checkpoint_execution_v1/README.md)。

GPU 队列沿用原有共享锁、32 GiB 可用物理内存、42 GiB 提交内存余量和 14 GiB 可用显存门槛，以及原有运行中保护。启动时核验了全部固定源文件、100 个模型配置及锁定的原生 LS4 环境，核验过程没有导入 Torch 或占用 CUDA。等待控制器的实际 PID、创建时间及资源快照见[运行观察](runtime_observations.json)。

[全部 100 个任务与实际系列数](original_full_training_jobs.csv)；[120 个待完成指标槽位](pending_native_metrics.csv)。待完成指标分为最终模型和原生测试选择的最佳模型，逐折、逐分支列出 MSE、CRPS、完整 NLL，均为 **0/5 种子、空值**，没有填零或诊断分数。

## 新完成的 GRASP 原始实验

规范槽位：`grasp_protocol_v3__tau_0p25__swan__swan_sf__seed1103`。精确恢复后的执行别名没有增加训练种子。完整预算与历史已核验：**1500 轮、93,000 次更新、3,935 个验证点、72,000 个测试点、69,244 个参数**；使用原定 5 个源样本、10 次 flow 评估。

| 口径／技术指标 | 实测值 |
|---|---:|
| 验证第 99 百分位定阈值、无 PA：Precision | 38.7339% |
| 同口径 Recall | 83.8308% |
| 同口径 F1 | 52.9858% |
| 测试标签选择最优阈值、无 PA：Best-F1 | 53.0506% |
| 原生 PRC，源码字段名为 AP | 0.520136 |
| 原生 AUROC | 0.721708 |

该组合只完成 **1/10 个训练种子**，没有种子 STD 或置信区间。测试标签选阈值的 Best-F1 与验证阈值对照分别列出；未取得作者等价或严格 TAB 认证。

[完整训练结果](tau025_full_native_training_result.json)及[1500 轮训练历史](tau025_full_training_history.jsonl)均已保存。实际训练检查点与全部原始数据、分数和预算绑定核验通过；该新模型的完整独立重推断在单独的受限 CPU 槽运行，尚未标为完成。之前 13 个训练检查点的重推断也继续推进，已完成部分保留，不重复增加种子。

最新规范 GRASP 全实体种子组为 **14/480**。新增实际训练结果贡献 6 条指标；[新版完整指标表](../all_algorithm_dataset_metrics_v11/results.html)有 **7,117 条记录：1,786 条实测、5,331 条缺结果**。这张表只更新 GRASP，其他轨道保留此前捕获时间；新增 USHCN 待完成槽位单独明确列出。
