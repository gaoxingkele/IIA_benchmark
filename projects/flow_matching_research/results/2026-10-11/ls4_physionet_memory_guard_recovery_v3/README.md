# LS4原生PhysioNet完整训练内存保护恢复

此前GT-GAN报告中的LS4第25轮快照是当时真实进展。随后终态复核发现：首项插值seed42的500轮训练在第25轮、2513次更新处因提交余量降至15191674880字节，触发原16 GiB紧急保护而中止。峰值私有占用29131476992字节，尚无500轮结果。不得继续声称该训练子进程仍运行；本目录补充终态证据，原快照、回执、模型/优化器/RNG保存和全部部分产物不改写。

[真实保护中止回执](preserved_full_training_guard_failure.json)；[最后实际训练进度](preserved_training_progress.json)；[交接前旧控制器状态](preserved_controller_status_before_handoff.json)。

根据完整训练观察，将启动提交余量由42 GiB提高至52 GiB，原32 GiB物理内存、14 GiB显存准入以及16 GiB提交余量/4 GiB显存紧急保护均保持。模型、500轮、6400/1600患者、41变量、64/32原批量、2个原生任务、5个种子、10项完整训练及750000次更新全部保留。

为避免同一不足准入条件在下一个种子上重复触发，已在确认旧控制器PID与创建时间后暂停其调度，检查无实际训练子进程且active_pid为空，再仅终止空闲旧控制器，启动v3继任者。未终止仍在训练的工作进程。[空闲交接证据](verified_idle_handoff.json)；[新控制器启动回执](controller_launch.json)。

新队列逐项保持原canonical任务ID、配置与种子，使用全新输出和F盘产物目录。失败seed42将从同一冻结种子重新跑完整500轮；这不是从部分模型续训，也不增加独立种子或合并部分结果。两项已通过的全量GPU容量证明依赖完整原队列与源码校验，并在新控制器启动前检查全部科学配置一致，因此不重复运行相同的一轮诊断。插值原模型参数535054、外推原模型参数783310，均按实际原容量回执核验。首版开发检查错误地假定两者参数相同，已在实际任务启动前修正；未影响原模型或任何实验结果。
