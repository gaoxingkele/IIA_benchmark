# WT-Flow 全测试集积分设置对比与独立重放

相关作者完整 Git 提交中的 `main.py` 训练入口默认 50 步，`infer_config.py` 默认 1 步，`infer.py::step_test` 原始扫描为 1、10、20、50、100、200 步。扫描代码实际只激活 transistor 类；本队列对全部 15 类的扫描是明确记录的本地扩展。AST 与 SHA 核验保留这些设置，没有按测试指标挑选赢家。目标 Flow Mismatching 未固定 WT 图像适配的积分器及步数，因此这组相关源码敏感性实验不能替代尚未认证的目标原始设置。

已登记并启动 30 个完整评分/独立重放任务：六种积分步数 × 五个独立训练种子 1103–1107。每项等待原有完整 2,000 轮、45,289,539 参数模型的不可变终轮检查点，覆盖全部 1,725 张 MVTec 测试图像和 15 类。原训练预算、3629 张正常训练图像、模型、优化器、BF16/TF32、数据审计和资源门槛均保留；评分复用同一模型，不增加训练种子。

评分使用原生反向流 Euler 端点及明确的 all-C/H/W LayerNorm、epsilon 1e-5，按目标原文 p22 Eq25 计算正的半通道平方和。相关原生特征代码使用负的半通道平方均值，这个差异已单独登记。图像标量采用已有本地 max+top-ceil-1% 均值规则；全量图像/像素 AUROC、AP、F1max、AUPRO 分别逐类计算再宏平均。F1max 是测试标签 oracle 报告，不是部署阈值或严格 TAB 结果。

每个候选须重新严格加载完整检查点，对每张测试图像独立执行 Euler、Eq25 和排序标量归约；随后用独立 sklearn 曲线及 CDF AUPRO 全量复算。模型重放容差 2e-6 和指标容差继承原已冻结评分配置，未根据观察到的结果调整。所有失败、检查点、输出和原始数据保留在 F 盘数据目录中。
