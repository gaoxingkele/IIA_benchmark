# 完整实验的实际进程核查与资源等待

本轮为已核验等待：六个原生训练进程的 PID、创建时间及完整命令仍一致，而且 CPU 时间均继续增长。
八个独立回放/后处理队列的实际所有者仍在运行。没有新增训练、减少预算或改动资源阈值。

旧的 Recovery TAB 和 GIFlow 跟进等待状态都有后续完成记录；不能根据旧状态重复启动。TCCM 的后续完整恢复队列也已核验仍在运行。
Windows 提交内存余量为 21.85 GiB。原始 GT-GAN 队列要求 42 GiB，SAITS 回放要求 28 GiB。
共享 GPU 还由完整图像训练使用，其他 GPU 任务保持原始互斥规则。

PhysioNet 十个原始 CUDA 模型已全部重新推理，但只有九个通过原阈值的逐患者统计一致性检查。
剩余失败继续保留，未放宽容差或声称严格复现通过，也未据此断言具体后端原因。

本轮没有新的完整性能结果。45 篇论文、681 条方法/基线/消融、273 条原始数据任务的完整范围继续保留，目标仍未完成。
