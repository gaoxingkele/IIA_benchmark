# GP600 原始失败诊断与新增完整重放记录

本轮新增两个完成训练、完整原始网格重放及独立逐点复核的 CFM 记录。自动收集器当前记录数为 132／285；本轮重新读取四个模型的证据链和全部预测坐标，其余记录沿用先前证据，全部研究范围仍为 45 篇论文、681 项方法／基线／消融记录及 273 项原始数据任务。

两种原始配方的数据划分和训练更新数不同，保持独立。报告和完整原始数组已绑定 SHA256，两个新记录均有原生模型重放、独立逐点指标验证以及未触发资源终止的执行凭证；它们不是 TAB 异常检测分数，也不证明与论文作者结果等价。

附录 GP600／Sine 的五个原始种子中，1104、1106、1107 完成原始评分，1103、1105 在评分阶段报 `AssertionError: underflow in dt 0.0`，均未触发资源终止。因此完整五种子均值保留为空，不以三个成功种子的均值代替。

seed1103 原评分完成 14／80 条轨迹后失败。其保存模型 SHA256 为 `3c41eff2f64660732be5528f6a204717df1bb8967e607bbd05c6ec9d1e3881b3`。上次注册脚本误引用不存在的依赖，未生成配置或启动诊断；已修正注册，并保留失败测试 XML。新配置及 12 项相关测试通过。唯一一次诊断控制器已实际启动，PID、创建时间和完整命令已核验；本轮发布时等待原配置的 30 GiB 提交内存余量，不持有共享执行锁。原始模型的完整预算元数据和全轨迹诊断仍待该原生工作进程验证，不能提前计为诊断完成。

`prepared_terminal_post_verification_source.py` 仅在原生诊断凭证完成后执行独立复核：检查全部 40000 个网格坐标，保留每个失败轨迹及原求解器设置，不进行追加训练、求解器调用或失败后反复尝试。诊断过程的成功退出仅表示失败取证完成，不表示原始基准评分成功。

BRITS、MaelNet 和 Pi 的当前训练进程均按实际 PID、创建时间、完整命令及 CPU 活动核验存活，见 `current_verified_actual_experiment_handles.json`。本轮未中止训练、缩减实验预算或放宽资源及数值容差。
