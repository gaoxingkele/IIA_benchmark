# GP400 两种目标解释的完整已训练种子配对

本轮归档附录GP Gaussian-conditional／Sine／seed1103的完整模型重放及独立全网格证明，并与同一数据文件、同一划分和seed1103的paper-literal模型配对。两个模型均完整训练400 epoch／250000 updates，原模型参数仅 `target_mode` 不同。每个模型的全部80×500×1预测、原始模型／数据字节和原生／独立资源凭证已重核。

| 目标解释 | 完整原始MSE |
| --- | --- |
| paper-literal | 0.0005067401359505417 |
| Gaussian-conditional | 0.008315532802160193 |

Gaussian-conditional减paper-literal的配对MSE差为0.007808792666209652；对80条完整测试轨迹做5000次配对分组bootstrap，95%区间为[0.005948692302045026, 0.009932501610514106]。Gaussian-conditional在1／80条轨迹上误差更小，在79／80条上更大。

此区间条件于这两个已训练模型，只重采样完整轨迹；500个时间坐标不当作独立组，也不估计训练种子变化的置信区间。固定的五个原始训练种子1103至1107仍全部需要，完整五种子变种比较未完成。因此本例不能宣布总体方法排名、作者等价或严格TAB性能。

目标解释差异在训练前已注册；本次只重读原始数组，没有追加模型推理、训练或基于测试表现选择目标公式、预算及参数。其余实验继续使用原数据、原预算和全部资源门限。源队列已进入下一GP400种子；两个BB400权限故障完整重跑控制器实际存活，仍等待同一训练家族锁，未计为完成。

11项相关验证通过，见 `validation.xml`。完整研究范围保持45篇论文、681项方法／基线／消融记录及273项原始数据任务，CFM完整注册规模仍为285。当前系统分页文件方案尚未应用。
