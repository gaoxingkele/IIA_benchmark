# 恢复两个未保存的 BB400 进度写入失败

原始执行凭证确认，主文 BB400／Sine 的 seed1104、1106 分别在第61、313 epoch因 Windows 进度 JSON 临时文件替换被拒绝而退出。两个任务均没有保存模型或完成结果，未触发资源终止。这两项不能归入数值失败，也不能把已经执行但未保存的训练计入重跑预算。

新增隔离运行入口沿用原 `run_cfm_ts_original_job.run` 的代码对象。仅替换 JSON 发布函数：使用唯一临时文件；发生 `PermissionError` 时最多8次有界重试；持续失败仍明确退出并保留此前元数据。重试的是文件替换，不是训练、采样、优化器更新或求解器调用。

两个任务都注册为原始完整400 epoch／6400 updates／20×500×1测试网格，数据、划分、种子、模型配置、采样及求解器不变；不加计第61或313 epoch的旧训练。新输出目录与原目录分离，原失败凭证及日志完整保留。

原始285个规范任务仍全部存在，只为两个未保存任务建立新的执行别名。训练沿用原22 GiB提交内存准入、16 GiB应急余量及同一个CFM训练家族锁；完整模型重放与独立逐点核验沿用原30 GiB准入和原容差。没有降低资源保护或停止既有训练。

完整训练控制器和自动模型重放／独立复核控制器均已实际启动，PID、创建时间和完整命令见 `actual_launched_controllers.json`。发布时训练控制器等待原CFM训练占用的家族锁，复核控制器等待这两个新模型的完整训练结果。两项尚未计为训练完成或成功指标。主文 GP600／seed1107 的完整模型重放及独立逐点凭证本轮另行归档，完整MSE为0.14057243235091274，原预测与重放最大差异为0；当前主收集器已验证135／285。

全285任务绑定、两项完整预算、其他283条路由保持、原数值代码对象、持续文件锁失败边界及补充复核的选择范围均已验证。本轮关联验证13项通过；文件写入单元测试仅验证I/O逻辑，不是基准性能。

研究范围继续保持45篇论文、681项方法／基线／消融记录及273项原始数据任务。原模型和大数据保留于 `F:/aicoding/IIA_Data`；本地实现为论文重建，作者等价复现和严格TAB结果仍未证实。
