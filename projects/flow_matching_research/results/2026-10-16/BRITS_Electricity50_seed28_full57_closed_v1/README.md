# BRITS：Electricity 名义50%缺失率，seed28完整闭环

原6,993,328参数模型按冻结的最大10000 epoch、patience30及验证集选择规则自然结束：next_epoch=768，最佳epoch源索引736。源训练、完整检查点CPU重推理、独立新进程全坐标复核及三阶段资源守卫均通过，未缩减预算、重训或替换数据。

实际测试网格为290×100×370，共10,730,000个坐标、4,221,734个留出目标和10个月份组。独立复算MAE=1.0519082629504706、RMSE=1.5655934200907982、MRE=0.563139411732428。作者有放回掩码抽样使实际留出比例约39.345%，不能解释为无放回精确50%；这些是原标准化单位的插补误差，不是异常检测F1。

模型、数据、恢复状态、原指标、原生预测与分组统计重新核验哈希；原NumPy1.23.5、seed10028的月份bootstrap区间重新执行并与原报告完全一致，原2e-6容差未改。该区间描述单模型月份敏感性，不替代5个独立训练种子的不确定性。

另附相同数据与留出目标下的SAITS/BRITS seed28配对结果。BRITS该缺失率已闭环seed26、27、28；29、30仍待完成，不能据此宣称完整五种子比较。原210项队列当前至少57项通过完整复核，seed29由原队列接续。

35项相关验证通过。论文历史逐缺失率调参、预处理种子及1397/1400序列差异仍未完全对齐，不认证原论文端到端等价或完整TAB结果。总体研究任务尚未完成。
