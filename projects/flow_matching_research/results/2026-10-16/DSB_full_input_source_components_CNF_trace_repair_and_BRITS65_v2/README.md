DSB 单细胞源码适配与 CNF 实际失败后的隔离修复

本轮继续保留全部45篇论文、681个方法/基线/消融记录、273个数据任务、702个论文标量目标及其他完整实验队列。新增完整性能结果为0；30项相关检查通过不代表实验已复现。

DSB 接入原作者 ScoreNetwork、CacheLoader 和 Langevin。按 OT-CFM 附录 E.4 配置两套独立网络：16/32 LeakyReLU 编码器、三层64 SELU 解码器，每套14261参数，共28522。与9093参数的CFM不能直接宣称参数或算力完全匹配。原 drop_last 缓存批次在单细胞端点不足10000条时为空；显式固定种子有放回采样保留所有端点训练行的抽样资格，粒子数仍为10000，20步产生200000条缓存，训练批次512。反向采样端点方向和第10步中点单独登记；指定留出点不进入端点训练数据。

DSB V1 尚未启动数值worker时，代码审查发现时间表默认float32与原主循环NumPy float64不一致。V2只改变worker中的一个dtype关键字，保留原时间表精度、全部输入、缓存规模和守护条件。交接时实际检查PID及创建时间，区分仅有的私有隐藏conhost子进程并证明没有数值后代；未暂停或终止任何数值worker。旧V1与交接证据完整保留。

原IPF代码使用包含端点的循环，每轮10001次更新，20轮双向共400040次/模型。后续五种现有完整输入、12个留出条件、五种子共60模型仍待完整原IPF训练器/环境接入、训练和重放。gamma=0.001与论文另述sigma=1的映射尚未获证实；实际环境是锁定的现有Py310/Torch1.12作者核心环境，不冒充原2021环境。本轮真实输入预检覆盖全部12分支，两方向完整缓存与梯度、完整早期端点人口的20步反向采样，但零优化器更新，不是训练结果。

CNF V1 获得原定资源后实际启动，完整1024批次在原CNFReg.forward报错：每个样本的trace[B]与零状态项[B,5]相加，维度不匹配。该次退出码1、资源守护未中止，原始stderr和guard完整保留。独立实例适配器保留原exact-trace、符号和零状态图连接，仅将恒为零的特征项整理为[B]；原版增广向量场和解析Jacobian、权重梯度、状态梯度在B1/5/1024通过验证。修复不改原作者类/文件，之前的留出索引修复保留。

CNF V2 重新登记同样5个完整输入、12个留出分支、1024批次、9093参数、原求解精度、优化器和32GiB门槛。DSB V2与CNF V2的精确句柄和本次状态见iteration_status.json；本次快照仍在等资源，未完成原生预检。CFM、CrossAD、MOMENT、SAITS既有数值worker实际CPU时间继续增长。所有训练、完整重放、独立指标与统计闭环仍按原标准要求完成。
