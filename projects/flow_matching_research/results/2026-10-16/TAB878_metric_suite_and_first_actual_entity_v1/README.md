# TAB 原始指标套件与首个真实实体结果

本轮接入原有 873 项完整原始数据实验和新增 5 项 DCdetector 公共切分对照，共 878 项、2057 组标签口径、87798 组实体与标签组合。完整目标没有缩减，其他论文和作者专用队列继续保留。

评估直接调用固定 TAB 提交中的全部 6 个分数指标和 15 个标签指标。每个实体、每种标签口径执行 6 个分数指标，以及 15 个标签指标在 3 个验证集阈值和 10 个原始诊断阈值下的结果，共 201 次调用。所有实体独立评估，范围指标与 affiliation 不拼接相邻实体。VUS 保留原始标签异常段长度中位数、全部整数范围窗口和 250 个阈值，没有缩小积分或阈值网格。

验证集阈值与使用训练／测试分数的原始诊断网格分列，不挑选最优测试标签、方向或阈值来排名。VUS 内部的范围容差由测试标签计算，这是原始指标定义，单独披露。未定义值、原始函数异常和警告逐项保留，不能补零或静默排除。实体宏平均提供总数与有限值覆盖；仅当全部实体有有限值时计算完整宏平均及固定 200 次实体 bootstrap 区间，有限子集平均另列，不能冒充完整结果或训练种子不确定性。

只有真实生产者、检查点原生重载以及独立进程的全部标签指标复核都已通过，任务才进入本套件。只读取已有预测，不训练、不重新推理、不修改原输入及阈值，不将旧 V2 与新公共 105 点切分结果混合。保持原 16/28/16 GiB 内存门槛、3/6 GiB RSS/private 上限和原审计锁，实体之间释放锁。

22 项验证通过。初次检查发现 Python312 缺少 statsmodels，原失败 XML 与哈希保留；随后将 statsmodels 0.14.6 与 patsy 1.0.1 安装到 F 盘独立目录，保存 wheel、安装报告及所有文件哈希。没有修改共享 Python 环境的依赖，也没有重新运行失败的科学任务。指标使用统一固定的只读评估环境，不能据此认证历史作者依赖环境等价。

## 已实际完成的第一个实体

TranAD Float64、种子 1103、原始完整 SMAP 任务的 A-1 实体，覆盖全部 8640 个测试时间点、4 种标签口径和全部 804 次调用。源模型和完整 54 实体预测此前已通过原生回放。本实体指标进程现已退出 0，实际守卫通过且未触发资源中止；772 个指标为有限值，32 个 affiliation F／precision 结果未定义，均保留。这不等于完整 SMAP 指标已完成。

在主标签口径、验证集 1% 假警报阈值下，F1 为 0，点调整 F1 也为 0，而 affiliation F 为 0.6847183650。ROC AUC 为 0.4952692625、AP 为 0.0099825022、范围 ROC AUC 为 0.5923386683、VUS ROC 为 0.5632691324、VUS PR 为 0.0173532158。同一批预测在不同定义下数值可以明显不同，不能把 affiliation 值当作 F1，也不能拿这一实体推断完整数据集或其他论文的真实性。

存档时控制器继续处理后续实体；878 项全部指标、其他种子、完整宏平均及跨算法配对比较尚未完成。这里是原始 TAB 度量控制，完整 TAB 数据切分、训练策略和作者历史复现仍是独立未完成要求。
