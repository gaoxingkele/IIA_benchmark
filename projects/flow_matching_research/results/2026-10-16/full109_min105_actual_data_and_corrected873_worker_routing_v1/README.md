# 原始 109 实体的 105 点公共切分与实际执行路径复核

本轮完成的是实际数据准备和执行组件，不是全部模型实验完成。原始 45 篇论文、681 项方法记录、273 项数据任务、702 项论文标量目标，以及原有 873 项完整原始数据实验和 2037 组标签复核任务均继续保留。

## 已实际完成的数据工作

新增公共切分版本仍覆盖 SMAP 54、MSL 27、SMD 28 个实体，保留 100 点隔离段和原训练比例规则，将最小验证长度从 100 提高到 105。原始文件、旧版数组、模型配置和运行任务均保留。

两个实体改变切分：SMAP D-12 使用拟合区间 [0,107)、隔离区间 [107,207)、验证区间 [207,312)；MSL T-9 使用 [0,234)、[234,334)、[334,439)。这两个实体仅从新的拟合段重算修复和归一化统计，保留全部测试点。其余 107 个实体的全部输入和主标签按 dtype、shape、内容字节与已完成 V2 版本逐一核对；全部 298 组实体标签覆盖也完全一致。

实际准备进程已退出 0，资源门控通过、未触发中止。保留原 16 GiB 物理可用、21 GiB 提交余量、16 GiB 紧急线及 3 GiB RSS/private 上限。全部原始数据哈希、独立逐坐标重建、序列化回读、109 个实体和 191 份既有 CSV 映射检查保留。NASA 原始 TEST 已预缩放的限制继续披露，不能认证全流程全局归纳性。

## 纠正此前的窗口风险判断

V1 几何检查错误地假设所有方法都调用通用的不补齐窗口函数。实际 MOMENT 队列调用专用 `run_moment_pretrained_job.py`，它已对短段进行右侧末值复制，并只保留真实长度的目标分数。因此，原先 11 项风险中 6 项 MOMENT 预测属于误判，不能称为已失败，也不能用来重启或替换原队列。V2 路径复核实际检查全部 873 个任务和 436 个数组头；真正尚未解决的长度冲突为 5 个 SMAP DCdetector 任务，其 105 点窗口无法评分旧版 D-12 的 100 点验证段。这些仍是静态预测，未冒称实际终止失败。

MOMENT 专用脚本的末值补齐仍标记为已观察上下文。新实现增加官方原生 observation mask 的独立预处理对照：固定 512 点架构、batch 1、0 个微调 epoch、种子 42，补齐仅用于张量存储，既不作为观察值，也不作为评分目标；未满 8 点的末尾 patch 保留官方 patch 掩码规则，所有真实时间点仍需评分。完整 512 点窗口继续调用原始评分实现。Small、Base、Large 三份新配置使用原权重和引用，不宣称历史论文权重等价。

## 已接入、尚待实际执行的核验

三种官方权重的原生掩码核验已启动控制器，计划覆盖每种权重的 10 个短长度（共 30 项），比较补齐值 0 与 10000 时真实分数的内容字节，并与原始完整 512 点分数核对。该核验使用确定性合成输入，只验证协议，不能记作真实数据集性能。

5 个 DCdetector 种子 1103—1107 的新对照使用完整 SMAP 54 个实体和已审计的新切分，保留原本地模型的 105 点窗口、256 隐藏宽度、[3,5,7] patch、3 层、batch 256 及 **3 个 epoch**。原配置的 3 个 epoch 不能认证原论文完整训练预算。新结果也不能与旧 V2 输入下其他方法的分数直接合并为同协议排行榜；配套方法的新切分对照、独立原生回放、全部标签复核和配对五种子不确定性仍需完成。

存档时两个新控制器都实际存活，但提交内存余量不足原 32 GiB 准入线，尚未开始数值子任务。保留原 16/32/16 GiB CPU 门槛、10/12 GiB RSS/private 上限和共享严格 CPU 锁，不降低门槛、不借用较宽松锁、不停止正在运行的科学任务。当前新增模型成绩为 0。

## 验证与来源

相关验证共 111 项通过。新 DCdetector 测试首轮误把 epoch 读取为内层字段并假定为 100，导致一个测试失败；已改为核对实际外层字段的 3 个 epoch。旧配置和失败 XML 保存在 F 盘，并记录哈希，仅在新任务启动前刷新测试绑定，没有更改原模型或重试科学任务。
