# 5 项完整 SMAP 对照的原生回放与 20 组标签复核

已为新增的 5 项 DCdetector 公共 105 点切分对照接入三阶段验证，覆盖完整 SMAP 54 个实体、种子 1103—1107 和全部 4 种标签口径，共 20 组标签结果。这里只是组件接入，真实训练尚未结束，当前不能宣称这些实验或完整研究目标已经完成。

首先要求实际数据准备证明、原始生产者成功退出、资源守卫回执、原始配置和输入文件哈希全部一致，再重新计算保存分数的全部原指标、验证集阈值、事件指标、bootstrap 200 次和阈值网格。随后从检查点恢复全部参数与缓冲区，保持原 2 个 CPU 线程和参数标志，不调用拟合，再对每个实体的训练、验证、测试全部窗口和尾窗重新推理。所有分数与标签都要求 dtype、shape 和内容字节一致，并验证序列化回读及推理前后权重不变。最后在另一个进程中从全部原始与原生分数再次重算 4 种标签结果。

数值部分复用已固定的完整 873 项指标与 105 项基线回放实现；只将数据与生产者绑定指向新的公共切分。DCdetector 的所有注意力头、层、patch、源 FP32 评分程序和独立 FP64 数学检查均保留原 2e-6 容差。完整理想 FP64 端到端差异仍单独记录，不能把逐步数值核对说成所有网络内核的独立重写。

原始本地模型保持 105 点窗口、256 宽度、3 层、[3,5,7] patch、batch 256、3 个 epoch，不代表已完成原论文训练设置。纯指标阶段保留 16/28/16 GiB 门槛、3/6 GiB RSS/private 上限和原审计锁；原生推理与复核保留 16/32/16 GiB 门槛、10/12 GiB 上限和严格 CPU 锁。原始失败和中途输出保留，不自动重试，不改动其他科学任务，不将新切分结果与旧 V2 分数混合排名。

24 项测试通过，其中包括一次完整原本地规模和 3 个 epoch 的小型 CPU 训练，再由三个独立进程完成指标重算、真实检查点重载和新进程复核。该测试使用两个合成实体，训练 107 点、验证 105 点、测试 217 点，覆盖 12 个窗口和 858 个真实坐标位置；只证明流程与数学检查可运行，不能当作 SMAP 成绩、CUDA 验证或原论文复现。没有伪造科学守卫回执。

存档时新控制器真实存活，等待 5 个生产者的实际结果与成功守卫回执；已完成的真实对照数为 0。匹配其他方法的新切分实验、配对五种子统计、完整 TAB 度量及历史作者协议仍需继续。原始 45 篇论文、681 项方法、273 项数据任务、702 项论文标量目标以及原有 873/2037 轨道保留。
