# MTDA 方法诊断与 CCF-A 改进方案

日期：2026-10-15

材料：`revised/张令羽/实验.md`，`revised/张令羽/七模型指标对比.xlsx`

对照：MTGFlow (2023)、CATCH (2025)、CrossAD (NeurIPS 2025)、MtsCID (2025)、LatentFlow (2026)、PaAno (2026)、MTDA（五个种子 2023–2027 的均值）。PaAno 在表注中为 seed 0。七个数据集等权宏平均。阈值类指标是各方法自己的逐项最优结果，不等同于验证集选阈值后的一次部署。

这份报告回答三个问题：创新缺在哪里；现有算法为什么仍然有效；若目标是 CCF-A 研究论文，方法应当改成什么样。结论先说在前面。

当前 MTDA 不是一个新的估计量。它是五类已经存在的分数按固定顺序接在一起：冻结的 patch 表征、掩码上下文、只保留条件细节项的三角流、状态近邻上的能量残差，以及通道活跃度记忆。七数据集宏平均好于这张表里的六个对照，原因是这些分数各自补上了密度式异常检测的一种已知失败，不是因为出现了不能被拆开的新机制。按现在的写法投稿，NeurIPS、ICML、ICLR 过不了“增量组合”；KDD 或 AAAI 的 research track 也过不了，除非下面第 3 节的改法真正落地，并且合成实验能预测真实数据上的输赢。

## 1. 创新缺失的核心

笔记里的三条创新点都是动机，不是被训练出来的对象。

| 笔记中的说法 | 代码实际在做的事 | 审稿人的归类 |
|---|---|---|
| 区分“状态少见”和“真正异常” | 三角流写成 \(p(h,d\mid c)=p(h\mid c)\,p(d\mid h,c)\)，检测时丢掉第一项，只留 \(-\log p(d\mid h,c)\) | 分数选择 |
| 按当前状态定位更可疑的时间区域 | Flow 对每个 64 点 target 只出一个标量；位置来自语义向量的 20 近邻能量中位数，再按 50% 均匀、50% 残差摊回 64 个点 | 与似然脱节的后处理 |
| 联合建模局部细节异常和整体活动异常 | Detail 与 Activity 各自做验证集上尾校准，然后 \(S(q)=q_A(q)+q_D(q)\) | 晚期融合 |

缺的不是“模块太多”，而是下面四件事都没有发生。

第一，问题被说清楚了，估计这个问题的模型没有。多工况序列里，少见不等于坏，这是条件异常检测的老问题。丢掉 \(p(h\mid c)\) 只是在三角分解之后做了一个选择。没有约束要求正常数据上的分数与状态稀有度无关，也没有定理说明什么时候该丢、什么时候不该丢。SMAP 上的退步就是这个空缺：那里不少异常是单点、单通道偏离，不是“状态对、细节错”。

第二，标量 \(d\) 是手工能量，不是学出来的充分统计量。它由冻结卷积特征图相对时间均值的平方偏差取对数，再用训练集中位数和 MAD 标准化。Flow 的主检测分支是在给这一个数做条件密度。高维密度难估，缩到一维以后当然稳。这是降维，不是新的流模型。笔记末尾未写完的那句“提取整体特征 \(d\) 的效果比……”如果成立，增益来自这个统计量，不来自 Flow Matching。在消融做完之前，不能把论文写成流模型论文。

第三，时间定位不在生成模型里。50/50 是固定常数，不是目标函数推出来的权重。均匀的那一半把 patch 分数铺满 64 点，残差的那一半把质量堆到能量偏离大的位置。这个折中是对着点级指标和区间级指标调的。换数据集或换指标就要重调。固定的 0.5 不能当作贡献。

第四，Activity 和 Detail 没有相互作用。通道标准差、Gaussian-rank、5 近邻是另一套记忆库。相加之前只做了各自的尾部校准，两路分数量纲可比，但模型不知道这一拍该信细节还是该信活跃度。笔记里的“局部和整体联合建模”在公式里没有出现。

表上的差距也撑不起“新算法显著更好”。宏平均里，MTDA 的 AUC-ROC 是 0.788，CrossAD 是 0.749；VUS-ROC 是 0.828 对 0.815；VUS-PR 是 0.491 对 0.467；Range-F1 是 0.331 对 0.295。Affiliation-F1 更低，0.733 对 0.770。点级 Precision 也更低，0.701 对 0.794。MTDA 是五种子均值，PaAno 只报了 seed 0。这种幅度、这种协议，不够一篇以方法贡献为主语的 CCF-A 论文。

一句话：你们定义了一个更好的检测问题，但没有发明一个专门估计它的模型。现有实现是把状态密度、细节能量、近邻残差和通道活跃度四套旧分数串起来再相加。

## 2. 这个算法为什么会有效

它有效，是因为这七个基准里的异常不是同一种东西，而流水线的每一段刚好补上了密度式检测的一种已知失败。下面按机制写，并写明哪一张表支持它、哪一张表否定“它普遍更强”。

### 2.1 丢掉状态边缘项，少把少见工况当成异常

正常工业序列常常有多个工况。工况本身少见，不代表这个工况下的行为坏了。PaAno 的分数是测试 patch 嵌入到正常记忆库的距离，少见但正常的工况会离记忆中心很远，于是被打成异常。

SWAT 把这件事暴露得很干净。PaAno 的 AUC-ROC 是 0.342，CATCH 是 0.244，MTDA 是 0.871，CrossAD 是 0.846。MTDA 在这里不是因为三角流更会积分，而是因为主分数问的是 \(p(d\mid h,c)\)：已经承认当前是这个状态，只问细节强不强得过分。少见工况只要细节轮廓还像同类正常样本，分数就不会升高。

PSM、SMD 上的领先是同一类收益的弱版本。PSM 上 MTDA 的 AUC-ROC 是 0.753，CrossAD 是 0.681，MTGFlow 是 0.642。SMD 上 AUC-PR 是 0.236，高于 CrossAD 的 0.186 和 CATCH 的 0.173；但 SMD 的 AUC-ROC 是 0.771，低于 CATCH 的 0.809 和 CrossAD 的 0.782。所以这条机制抬高的是“少见工况不再大面积误报”，不是每一个排序指标。

这条机制的边界也清楚。如果异常本身就是一个新工况，状态边缘项里才有证据，丢掉它就会漏检。后面的合成实验必须把这个反例做出来，否则“少见不等于异常”只是口号。

### 2.2 只给一维细节做条件密度，避开高维似然

\(d\) 的计算是：卷积特征图每个通道减去该 target 内的时间均值，再对通道和时间取平均平方偏差，取 \(\log(1+\cdot)\)，最后用训练集中位数和 MAD 标准化。它描述的是这一段在潜空间里的内部起伏有多强，不描述它是哪一种工况。\(h\) 描述工况，\(c\) 描述被遮住的 target 周围还剩什么。条件密度 \(p(d\mid h,c)\) 因此只问一件窄事：这种工况、这种上下文下面，这种起伏幅度正不正常。

同一幅度的起伏，在高方差工况里可以正常，在平直工况里可以异常。这是条件化本身的好处，而且被条件化的对象只有一维，Flow Matching 好拟合。MTGFlow 和 LatentFlow 要在更高维的表示上做密度，宏平均 AUC-ROC 只有 0.678 和 0.635，AUC-PR 只有 0.348 和 0.272。MTDA 的 0.788 和 0.425 里，有一大块是“拒绝做高维密度”换来的，不是速度场或 ODE 步数换来的。

因此要先做判决消融，不要先改网络。若“标准化后的 \(d\)，条件于 \(h\) 和 \(c\)，用一个很小的条件密度模型甚至用条件 MAD”已经接近完整 Flow 的 VUS-PR，论文主语就只能是这个条件统计量，不能是 Flow Matching。

### 2.3 掩码上下文去掉了用目标本身解释目标

上下文编码器把当前 64 点 target 的原始值遮掉，只读外层窗口里其余位置，并且不跨外层窗口。这样 \(c\) 不能靠抄 target 来解释 \(d\)。条件似然测的是：周围观测所允许的正常细节，和当前这段的细节差多少。

这和掩码重构式异常检测是同一条原则，但预测对象是一个摘要，不是全部通道的原始值。摘要更稳，也更丢信息。单点尖峰会被 64 点的平均能量稀释。这就是 SMAP 上 AUC-ROC 只有 0.577，低于 PaAno 的 0.670，也低于 MTGFlow 的 0.593 的直接原因。GECCO 上 CrossAD 的 AUC-PR 是 0.551，MTDA 是 0.457，同样说明整体细节强度对短而尖的事件不占优。

掩码这一步应当保留。它是流水线里少数几个原则正确、而且不依赖 0.5 这种常数的设计。

### 2.4 能量残差是同一句话又说了一次

逐时刻能量 \(E_i(t)\) 来自同一张特征图。\(d\) 是这些能量的总和经过压缩后的标量，曲线本身被留下来做定位。定位时用 \(h\) 的余弦近邻 20 个，取对数能量的中位数和 MAD，得到相对位置残差，再归一化成权重。

Flow 已经用 \(h\) 条件化了整体强度。近邻残差再用 \(h\) 条件化每一个时间位置。两路高度相关。相关的检测器投票，方差下降，宏平均变好看，所以它稳。它不是新的信息源。20、截断 20、尺度下限里的 0.05，都是固定常数。审稿人会要求把它们拿掉，看 VUS-PR 掉多少。若掉得很少，这一段就不能写进贡献。

### 2.5 50/50 是在买区间指标，同时卖掉边界

纯残差把一个 target 的全部分数堆到能量峰上。异常若是一整段轻微偏离，区间召回会掉。纯均匀把分数铺满 64 点，段被点亮，VUS 和 Range-F1 受益，但边界变脏，Affiliation 会罚。

表上的分裂和这个折中一致。MTDA 的 Range-F1 宏平均 0.331，高于 CrossAD 的 0.295；Affiliation-F1 是 0.733，低于 CrossAD 的 0.770，也低于 CATCH 的 0.757。SWAN 上 Affiliation-F1 只有 0.234，Precision 可以到 1，Recall 只有 0.147，说明高分打在了过宽或偏了的位置上。50/50 不是原理，是对着两族指标做的妥协。改进方案里这一项必须删除，不能再扫描 0.3、0.5、0.7。

### 2.6 Activity 补的是能量看不见的异常

Detail 看的是潜空间起伏。有一类异常起伏不大：某个通道卡住、整段方差变了、或者“哪些通道在动”的组合错了。Activity 对每个通道算 64 点标准差，做 \(\log\) 后按该通道正常历史做 Gaussian-rank，再拼接通道是否处于活动状态的 0/1 指示，然后在正常记忆里取 5 近邻的平均欧氏距离。

它和 Detail 看的错误不一样。两路分别校准后再相加，点级 F1 的宏平均到 0.455，CrossAD 是 0.394，Recall 是 0.631 对 0.565。Precision 却从 CrossAD 的 0.794 降到 0.701。多报出来的那一部分，就是第二路检测器在没有联合模型约束时交上来的假阳性。晚期融合能补召回，不能保证两路在同一时刻同时可信。

### 2.7 上尾校准解决的是尺度，不是检测原理

验证集上的 \(-\log\hat p\) 把原始分变成正常点里的尾部秩。Flow 的 Hutchinson 散度有噪声，Activity 距离是另一套单位。校准让它们能相加，而且只用正常验证点，不看测试标签，这一步是合法的。它解释不了为什么相加是对的，只解释了为什么相加在数值上不会被一路支配。

重叠 target 再取点级平均，是时间平滑。它同样推高 VUS，因为它在若干窗口尺度上把孤立噪声抹掉。平滑不是归因。

### 2.8 把第 2 节收成一句可证伪的话

MTDA 的分数是一个误差组合：少见工况的误报交给“丢掉 \(p(h\mid c)\)”，高维似然不稳交给一维 \(d\)，位置交给近邻能量，能量看不见的方差组合交给 Activity，尺度交给尾部校准，区间覆盖交给 50/50 和平滑。

这个组合偏向段状、上下文型、多通道工况异常。支持它的是 SWAT、PSM，以及 SMD 的 AUC-PR。反对“普遍更强”的是 SMAP、GECCO 的 AUC-PR、SMD 的 AUC-ROC，以及全表的 Affiliation-F1 和 Precision。

笔记里未写完的工作假设应当当成假设，不要当成结论：真正有用的可能是“用状态和上下文条件化之后的整体细节强度”，外壳里的三角流、20 近邻和 Activity 相加未必是增益来源。第 3 节的第一周就是测掉这个假设。

## 3. 完整改进建议

目标不是把宏平均 AUC-ROC 从 0.749 再抬到 0.80。那个增量救不了一篇组合论文。目标是把第 2.8 节那句话变成一个估计量：异常是对条件机制的干预，定位和融合都从这同一个机制里出来。

### 3.1 论文只保留一个主语

主语定成这一句，后面所有模块都要能放进这句话，放不进的删掉：

在只含正常数据的训练下，多元时间序列的上下文异常是条件核 \(p(u\mid s,c)\) 的改变，不是状态 \(s\) 的稀有。这里 \(s\) 是工况，\(c\) 是不泄漏当前片段原始值的上下文，\(u\) 是该工况下的行为，至少包含时间能量曲线和通道活动。检测分数必须对正常数据上的状态稀有度不敏感，并且点级位置必须是这个条件分数对时间的分解，而不是另一个模型乘上一个常数。

标题里不要出现“50%”“近邻”“多分支融合”。那些是现在的实现细节。

### 3.2 从现有流水线里保留什么、删除什么

保留：

- 外层窗口内遮住 target 原始值的上下文编码器。原则是对的。
- “状态”和“行为”分开表示。\(h\) 继续表示状态。被打分的对象从标量 \(d\) 改成行为 \(u\)。
- 条件 Flow Matching 可以作为 \(p(u\mid h,c)\) 的密度估计器。它是工具，不是贡献。贡献是条件核、不变性约束，以及分数沿时间的分解。
- 正常验证集上的尾部校准可以留在评测协议里，用于把不同方法的分数变成可比的尾部秩。不要把它写成模型的一部分。

删除，并且不要用新的常数替换：

- 检测时手工丢掉 \(p(h\mid c)\)。改成第 3.4 节的不变性约束。边缘项可以仍然不进入最终分数，但那是约束的结果，要在正常数据上被测到。
- 冻结 PatchEncoder 作为最终设定。冻结可以留作消融，主模型必须让编码器接到条件分数的梯度。否则不能说表示是为这个检测问题学的。
- 20 近邻、中位数能量轮廓、残差截断 20、尺度下限 0.05。
- 50% Uniform + 50% Residual。
- Activity 与 Detail 校准后相加。活动必须进 \(u\)，不能再做第二条记忆库。
- 为了刷 Range-F1 而做的重叠平滑，如果它不来自模型的时间分解，就只放进附录，不放进方法。

### 3.3 模型：一条条件路径，同时给出“有多异常”和“在哪一拍”

把每个 target 的行为定义成一条曲线加一组活动，而不是一个标量。

设 target 长度为 \(P=64\)。编码器输出三样东西，并且都接受梯度：

- 状态 \(h\in\mathbb{R}^{d_h}\)。只作条件，不作分数。
- 时间行为曲线 \(e(t)\in\mathbb{R}^{P}\)。可以用现在的逐时刻潜在能量作初始定义，但必须允许编码器改这张图。不要再把曲线压成 \(d\) 之后才送进 Flow。\(d\) 若保留，只能作为 \(e(t)\) 的一个可读摘要，用于消融，不用于主分数。
- 活动 \(a\in\mathbb{R}^{d_a}\)。用现在的通道级 Gaussian-rank 活动特征作输入是可以的，它是观测的函数。不要再对 \(a\) 单独做 5 近邻。

上下文 \(c\) 仍由掩码 Transformer 从外层窗口的非 target 位置得到。

在 \((e,a)\) 上做条件 Flow Matching，条件是 \((h,c)\)，不要把 \(h\) 放进被积分的变量。训练仍用线性插值。记 \(u=(e,a)\)，\(u_0\sim\mathcal N(0,I)\)，\(\tau\sim U(0,1)\)，

\[
u_\tau=(1-\tau)u_0+\tau u,
\qquad
\dot u = u-u_0,
\]

\[
\mathcal L_{\mathrm{FM}}
=
\mathbb E\left\|
v_\theta(u_\tau,\tau,h,c)-\dot u
\right\|_2^2.
\]

速度场在活动块和曲线块之间允许耦合，在状态块上不耦合：\(v\) 可以读 \(h\)，\(h\) 的坐标不进入 \(v\) 的输出。这样联合密度就是 \(p(e,a\mid h,c)\)，活动异常和曲线异常共享一个归一化常数，不再是两条分数相加。

推理时的 target 级分数只从这条速度场来：

\[
s
=
-\log p_\theta(e,a\mid h,c),
\]

用与现在相同的 ODE 与 Hutchinson 估计即可。不要再乘一个残差权重。

点级分数是这条路径对时间坐标的分解，不是标量乘权重。曲线坐标的训练损失本来就是逐点的。定义第 \(t\) 个时间位置的局部成本为速度残差在该坐标上的能量，在 \(\tau\) 上积分或在从数据端回到噪声端的 ODE 轨迹上求和。记曲线维的速度分量为 \(v^{(e)}\)，

\[
s(t)
=
\int_0^1
\left\|
v^{(e)}_\theta(u_\tau,\tau,h,c)^{(t)}
-
\dot e^{(t)}
\right\|_2^2
\,\mathrm d\tau.
\]

实现时用与训练相同的 \(\tau\) 网格做蒙特卡洛，不要再引入 0.5。活动块没有时间下标，它的成本加到该 target 覆盖的每一个点上，分母是 \(P\)，这样活动证据是均匀的背景，曲线证据才是时间上不均匀的部分。两者的相对大小由同一个 \(v_\theta\) 的范数决定，不由手写系数决定。

重叠 target 仍映射回原序列。点级输出取覆盖该时刻的 \(s(t)\) 的平均可以保留，因为这是网格重叠的几何结果，不是第二套归因规则。要在消融里报告“不平均”的 Affiliation-F1。若平均显著破坏边界，就缩短步长或只保留一个偏移，而不是回到 50/50。

这套写法删掉了近邻记忆。若第一周的消融显示，没有近邻以后 SMAP 或 SWAT 崩掉，不要把近邻加回去当主方法。那说明曲线流没有学到状态条件，应该检查 \(h\) 是否真的进入了 \(v_\theta\)，而不是恢复 20 近邻。

### 3.4 用不变性约束替换“我们选择丢掉第一项”

在正常训练批上，状态稀有度用一个停止梯度的代理 \(r(h)\) 测量。可用 \(h\) 到正常记忆的余弦距离，但这个距离只作惩罚项的协变量，不进入检测分数。记本批条件分数为 \(s\)，惩罚

\[
\mathcal L_{\mathrm{inv}}
=
\left(
\widehat{\mathrm{Corr}}(s,\, r(h))
\right)^2.
\]

总损失 \(\mathcal L_{\mathrm{FM}}+\lambda\mathcal L_{\mathrm{inv}}\)。\(\lambda\) 只在正常验证集上选，选择标准是：条件负对数似然不显著变差，同时相关落在接近 0 的区间。不要在测试集上选 \(\lambda\)。

需要报告的不是“我们把边缘项删了”，而是一张图：正常验证点上，\(s\) 对 \(r(h)\) 的散点在加惩罚之前有正斜率，加惩罚之后斜率接近 0；测试集上，少见但正常的工况不再占据高分位，上下文异常仍然占据高分位。斜率若压不下去，三角分解和“丢掉第一项”的故事就不成立，论文不能写这句贡献。

### 3.5 一个必须先写下来的命题，以及它的合成数据

没有这条命题，第 3.3 节仍会被看成“把标量 \(d\) 换成一条曲线的 Flow”。命题要短，假设要写明，反例要一起给出。

设正常数据由 \(K\) 个工况生成。工况 \(s\) 的边缘可以很不均匀。给定 \(s\) 和上下文 \(c\)，行为 \(u\) 服从核 \(P_0(u\mid s,c)\)。考虑两类干预，互不包含：

- 核干预：\(s\) 仍按正常边缘抽取，\(P_0\) 在一个时间区间上被换成另一个核。这是上下文异常。
- 状态干预：核仍是 \(P_0\)，但 \(s\) 抽到训练中极少或从未出现的工况。这是少见工况，按本问题的定义不是要报的异常。

在“测试时的状态后验不被核干预彻底改写”这一假设下，边缘负对数似然 \(\,-\log p(u)\) 对状态干预和核干预都敏感；条件分数 \(-\log p(u\mid s,c)\) 只对核干预敏感。因此只用边缘密度的流模型会在少见工况上误报，条件分数不会。反过来，若异常就是状态干预，条件分数应当漏检。这条漏检不是失败后的借口，是命题的另一半。

合成数据按这个生成过程做，不要用真实数据集的名字去“解释”。建议最小设置：

- 3 个工况，先验概率约为 0.8、0.15、0.05。每个工况一条不同的平滑模板，再加高斯噪声。通道数从 5 到 20 做两档即可。
- 核干预：保持工况不变，把模板的一个连续区间换成另一条模板，或把该区间的方差放大到正常核之外。区间位置随机，长度占总长的 10% 到 30%。
- 状态干预：以训练中没出现的第 4 个工况生成整段，核的噪声水平与正常相同。
- 点干预：在一个通道、一个时间点上加一个大幅尖峰。这是命题之外的压力测试，用来预测 SMAP。

必须出现的四张结果，缺一就不要写理论节：

1. 边缘流在状态干预上的假阳性明显高于条件流。
2. 条件流在核干预上的检出高于边缘流，或至少不低，同时状态干预上的假阳性接近正常工况。
3. 点级 \(s(t)\) 的质量落在核干预的区间内，不需要 50/50。用区间重叠或 Affiliation 的合成版本度量，不要只报一个标量 AUC。
4. 点干预短到一两个采样点时，条件曲线流变差。这句话用来预测 SMAP，而不是等 SMAP 掉了再解释。

命题的假设若不成立，就明确写成限制：核干预若同时把 \(h\) 打到另一个工况，条件分数会把异常吸收进状态，从而漏检。这是方法的边界，写进论文的 Limitations，不要藏。

### 3.6 第一周就要做完的判决消融

在改模型之前，用现有 MTDA 在 SWAT 和 SMAP 上做下面六行。两个数据集就够，因为一个是第 2 节里的正例，一个是反例。五个种子。主指标用 VUS-PR 和 Affiliation-F1，不要用测试集最优 F1 做判断。

| 编号 | 分数 | 要回答的问题 |
|---|---|---|
| A0 | 现有 MTDA 全系统 | 参照 |
| A1 | 只用标准化 \(d\)，不做 Flow、不做残差、不加 Activity | \(d\) 本身有多少 |
| A2 | \(d\) 条件于 \(h\) 的稳健 z 分数或很小的条件高斯，仍无 Flow | 条件化是否已经够用 |
| A3 | 现有三角流的 \(-\log p(d\mid h,c)\)，定位改为把标量均匀铺到 64 点，去掉残差 | Flow 比 A2 多出多少 |
| A4 | A3 加上现在的 50/50 残差 | 残差是否只在改 Affiliation，而不改 VUS-PR |
| A5 | A0 去掉 Activity | 相加是否只是在买 Recall、卖 Precision |

判决规则写死，避免做完以后再改口：

- 若 A2 相对 A0 的 VUS-PR 差距在 SWAT 上很小，论文就不要以 Flow Matching 为贡献。后面的模型仍然可以用流去估计曲线密度，但引言的贡献列表里不能出现“我们提出了一种新的流”。
- 若 A4 相对 A3 主要改变 Affiliation、几乎不改变 VUS-PR，50/50 就是指标妥协，按第 3.3 节删除。
- 若 A5 的 Precision 上升、Recall 下降，Activity 是一条独立检测器。它必须进入第 3.3 节的联合变量 \(u\)，不能继续相加。
- 若六行在 SMAP 上全部低于 PaAno 的 0.670 AUC-ROC 这一量级，就接受点异常不是本方法的目标，并在合成数据的点干预上复现这个失败。不要为了 SMAP 再加一条尖峰检测器。

这一周的结果决定第 3.3 节哪些句子还能留。不要并行开始写论文。

### 3.7 真实数据协议

宏平均可以保留，但不能是唯一证据。

- 主指标：VUS-PR 与 Affiliation-F1。AUC-ROC 降为辅助。测试集上搜索阈值得到的 F1、Range-F1 放进附录，并注明最优阈值使用了测试标签。
- 部署口径另报一列：阈值只在正常验证集的尾部上选定，例如验证集分数的固定分位，然后在测试集上算一次 Precision、Recall、Affiliation-F1。这一列才是方法能不能用。
- 所有对照，包括 PaAno、CrossAD、MTGFlow，都跑五个种子。现在的表不能直接进论文。
- 对照至少覆盖表中已有的六个，再加上笔记和仓库里已经在跑的、代表不同失败模式的重构式方法。不要只挑宏平均上弱的对照。
- 每个数据集单独报，禁止只报一行宏平均。SWAT、PSM 上的增益和 SMAP、GECCO 上的落差必须同时出现。
- 统计：以数据集内的实体或滑窗块为配对单位做检验，或者至少报告五种子的标准差。七个数据集的一个均值没有标准误会被直接打回。
- 不新增公开测试集上的调参循环。\(\lambda\)、ODE 步数、隐藏维只在正常验证集上定，然后冻结。

### 3.8 论文结构

按这个顺序写，不要按现在的工程流水线写。

1. 引言。用一个两工况的例子开头：工况 B 很少见但行为正常，工况 A 很常见但某一段的起伏核变了。边缘密度把 B 打成异常，把 A 的那段漏掉或只能整段点亮。用三句话定义贡献：条件核而不是状态稀有；分数在正常数据上对稀有度不敏感；点级位置是条件路径的时间分解。不要列“我们还融合了 Activity”。
2. 问题。写第 3.5 节的两类干预和假设。明确本方法不声称覆盖点状尖峰。
3. 方法。掩码上下文、行为变量 \(u=(e,a)\)、条件速度场、不变性惩罚、时间分解 \(s(t)\)。公式服务这四件事。50/50、20 近邻、两条记忆库不要出现在方法节。它们只在实验里作为“旧系统”的消融行。
4. 命题与合成实验。四张必须出现的结果放在真实数据之前。读者先看到原则成立，再看到真实数据符合原则。
5. 真实数据。先给 SWAT、PSM 这种核干预更像的数据集，再给 SMAP 这种点干预更像的数据集。SMAP 上输给局部距离方法时，用合成实验第 4 条解释，不新增模块。
6. 消融。第 3.6 节的六行，加上：去掉 \(\mathcal L_{\mathrm{inv}}\)、曲线改回标量 \(d\)、活动移出联合变量改回相加、时间分解改回均匀铺分。每一行只动一个因素。
7. 限制。状态后验被异常彻底改写时会漏检；极短尖峰会漏检；Hutchinson 估计的方差要报告。计算量如果明显高于 CrossAD，要单列，不要藏在复现细节里。

### 3.9 不要做的事

- 不要再加频域支路、图神经网络、预训练大模型或第二条记忆库。每加一条，论文就更像组合。
- 不要把 50/50 换成可学习的标量门控后宣称“我们学会了融合”。一个全局标量仍然不是时间分解。
- 不要用测试集最优 F1 的提升当主结果。
- 不要在引言里写“联合建模局部和整体”，除非活动与曲线已经在同一个 \(p(u\mid h,c)\) 里，并且消融显示拿掉耦合后退化成相加。
- 不要为了 SMAP 单独加尖峰头。那会把方法边界涂掉，命题也跟着失效。
- 不要在判决消融做完之前改写贡献列表。第 3.6 节可能证明 Flow 不是贡献。

### 3.10 工作顺序

按依赖关系做，不要并行铺开。

1. 判决消融 A0–A5，只跑 SWAT 与 SMAP，五种子，主指标 VUS-PR 和 Affiliation-F1。这一步决定论文主语。
2. 把被打分对象从 \(d\) 换成 \((e,a)\)，去掉近邻和 50/50，先不加不变性惩罚。在合成数据上确认时间质量落在核干预区间内。
3. 加上 \(\mathcal L_{\mathrm{inv}}\)。检查正常验证集上分数与状态稀有度的相关是否掉下去，同时核干预的检出还在。
4. 用第 3.5 节的四张合成结果冻结命题的措辞。做不到第 4 条就不要声称覆盖点异常。
5. 再跑完整真实数据协议。旧 MTDA 作为消融行保留，不作为方法主体。
6. 最后写论文。方法节只能包含第 5 步里仍然成立的部件。

若第 1 步发现 A2 已经解释了几乎全部增益，第 2 步不要再把工程量花在更深的 ODE 上。把贡献改成“状态条件化的行为统计量及其时间分解”，Flow 只作为估计器写进实现细节。这种收缩仍然可以成为一篇干净的 KDD 或 AAAI 论文。硬把流模型写成创新，反而会在审稿时被 A2 一行打掉。

以今天的手稿，不建议投。宏平均上对 CrossAD 的 VUS-ROC 差距大约是 0.013，Affiliation-F1 为负，定位规则是常数，融合是相加。

## 补完：笔记末尾被截断的那一句

`实验.md` 最后停在：“效果是提取了整体特征 \(d\) 的效果比”。下面把比较对象写完。没有内部消融的比较标明为假设，不写成已经测到的提升。

提取整体特征 \(d\)，再让它条件于语义状态 \(h\) 和掩码上下文 \(c\)，效果比下面两类已有做法更好，也比一类局部做法更差。

第一，比只用状态嵌入到正常记忆的距离更好。PaAno 就是这种距离。少见但正常的工况会离记忆中心很远。\(d\mid h,c\) 不问状态少不少，只问这个状态下的整体细节是否过分。SWAT 上 PaAno 的 AUC-ROC 是 0.342，MTDA 是 0.871。PSM 上是 0.538 对 0.753。这是七模型表能够支持的主要收益。

第二，比在更高维表示上直接做流更好。MTGFlow 和 LatentFlow 的宏平均 AUC-ROC 是 0.678 和 0.635，MTDA 是 0.788。收益来自检测对象被收成一维条件分布，不来自三角分解或 ODE 步数本身。

第三，比只保留逐时刻能量、不先做成整体 \(d\)，是否更好，现在没有这一行消融，不能写成已证实。现有系统是先把 64 个位置收成一个 \(d\)，Flow 只给这个标量打分，再按 50% 均匀加 50% 能量残差摊回去。整体 \(d\) 抓住的是段级幅度：形状还像、但整段起伏偏高。纯逐点形状距离会漏掉这种段。逐点能量只负责事后指出位置。这是先汇总、再摊回，不是联合分布。

第四，比有 \(d\) 和 \(h\)、但没有掩码上下文 \(c\)，应当更好，同样没有内部消融。\(c\) 用来阻止 target 的原始值解释它自己。这一句留作假设，由第 3.6 节的判决消融决定去留。

第五，比针对单点偏离的局部距离更差。SMAP 上 MTDA 的 AUC-ROC 是 0.577，PaAno 是 0.670，MTGFlow 是 0.593。GECCO 上 CrossAD 的 AUC-PR 是 0.551，MTDA 是 0.457。一个采样点的尖峰会被 64 点的整体 \(d\) 稀释。这不是实现疏忽，是整体统计量的分辨率上限。

所以截断句不能收成“局部和整体已经联合建模，所以效果更好”。能放进论文的版本只有这一句：在这七个外部对照里，状态和上下文条件化之后的整体细节强度，优于状态嵌入距离，也优于更高维上的流；它不优于单点局部距离。Activity 仍是另一路相加，逐时刻能量仍是事后摊分。有 \(d\) 对无 \(d\)、有 \(c\) 对无 \(c\)、有残差对无残差，三组内部对比都还没测。在这三组做完之前，\(d\) 只是工作假设，不是模块贡献。
