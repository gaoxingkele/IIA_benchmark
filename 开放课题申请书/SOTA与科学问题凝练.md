# 时序数据质量检测、智能修复、风险演化建模与动态预警：SOTA 全景与科学问题凝练

目的：把 IIA 库的复现实证、最新 SOTA（含 TimesFM-3 与 flow matching）与申请书四个模块对齐，凝练可申报的科学问题，并给出每条的研究切入点。本文作为申请书反哺与后续迁移分析的底稿，所有实证均可回溯到 `ara_mtsad/` 下的证据表。

## 一、SOTA 全景（按流派）

| 流派 | 代表方法 | 解决的核心问题 | IIA 实证发现的局限 |
|---|---|---|---|
| 重建流派 | TimesNet、iTransformer、USAD、OmniAnomaly | 以重构误差为异常分数 | 分数受阈值与点调整支配，检测锐度与段覆盖混淆 |
| 对抗重建+极值 | TranAD | 两阶段对抗重建 + POT/SPOT 阈值 | 两种阈值规则都试过仍不复现发表值；代表序列与全数据集混用 |
| 关联建模 | Anomaly Transformer | 先验-序列关联差异 | SMD 可复现到 0.0001，MSL/SWaT 明显偏离 |
| 对比表征 | DCdetector | 无重建的双注意力对比 | 残差随训练配置漂移，不随列也不随架构 |
| 频域流派 | CATCH | 频域分块 + 通道融合重建 | 其发表表属 affiliation 指标族，与点调整表不可直接比 |
| 因果/图流派 | GCAD、GANF、GDN | 以因果结构或图偏差为分数 | GCAD 梯度因果分数在短窗上低于随机（SWaT AUROC 0.393） |
| 预测偏差流派 | Telemanom、团队 CIKM'25 状态空间 | 预测残差 + 动态阈值 | 对协变量与跨序列信息利用弱（单变量历史） |
| 时序基础模型 | TimesFM-3（Google, 2026-08）、Chronos-2、Toto 2.0 | 零样本多变量预测 + 分位数不确定性 | 面向预测，非检测；概率输出为分位点而非全分布 |
| 生成/概率流派 | CSDI、SSSD（扩散）；Rectified Flow、CFM（flow matching）；GANF（normalizing flow） | 条件生成、插补、密度估计 | 修复验收多以重构误差衡量，鲜少以下游检测稳定性检验 |
| 基准批判流派 | TSB-AD、TAB | 把评估协议与可复现性本身当研究对象 | 指出"分数排名"对协议高度敏感，但未给出统一度量几何 |

流派层面的结论：SOTA 的演进不只是模型换代，更是评估协议的换代——重建/对抗时代由点调整 F1 主导，关联/对比时代引入区间度量，基础模型时代以分位数与概率度量为主。谁用什么口径验收，比用什么架构更决定结论。

## 二、IIA 库的关键实证（科学问题的证据底座）

1. 评估协议是一阶变量：点调整使同一批预测的 F1 抬升 2.8–116 倍；同一批预测在两个"区间/范围"度量族下差 0.53；窗口布局、阈值规则、切分版本各自可改分数。证据：`ara_mtsad/evidence/tables/protocol_sensitivity.md`、`range_metric_variant_check.md`。

2. 可复现性是方法属性：同一模型同一协议在 SMD 复现到 0.0001，在 MSL/SWaT 明显偏离；种子方差小、阈值 oracle 也到不了发表值。证据：`rerun_vs_published.md`、`rerun_deep_status.md`。

3. 因果分数的窗口尺度失效：GCAD 的梯度因果矩阵在短窗下不可比（SWaT 低于随机、SMAP 掷硬币），说明"尺度感知"是因果信号成立的前提。证据：`auc_family_check.md`。

4. 数据版本与分析单位不一致：SWaT 训练行数在文献间不同、代表序列与全数据集混用，同名基准掩盖不同数据。证据：`swat_split_audit.md`、`tranad_check.md`。

5. 三套度量族并存：点调整 F1、区间/关联、阈值无关 AUC 衡量不同对象，族间无统一几何，导致跨论文比较是范畴错误。证据：`affiliation_family_check.md`。

## 三、凝练后的科学问题（重排，供立项依据使用）

Q1（主，检测+评估）：质量缺陷的协议鲁棒检测。缺陷在时间—通道间耦合，而点级、段级、通道级、系统级语义各不相同；如何给出与预警决策代价对齐的度量，并把"段覆盖"与"检测锐度"解耦。

Q2（主，修复）：结构一致的生成式修复。以 flow matching/随机插值替代或补充扩散，把因果结构与物理约束嵌入流的学习目标；修复质量由下游检测与预警的稳定性验收，而非仅由重构误差验收。

Q3（主，演化）：尺度感知的多变量风险演化。融合因果图与流式轨迹推演，刻画风险在变量间的传播与时间演化，抑制短窗伪因果；并回答基础模型的跨序列依赖能否迁移到风险结构。

Q4（主，预警）：不确定性到动态预警的标定。统一"分数—不确定性—决策代价"，比较分位数预测（TimesFM-3 系）与全分布流两条概率路线，给出事件级、可标定的预警。

Q5（横贯）：可复现性与数据版本治理。把"评估协议是一阶变量"理论化，形成度量族几何、协议矩阵与版本治理规范，使可复现性成为方法发布的门禁。

与初稿相比的变化：原"低虚警定位"并入 Q1 的度量部分；新增 Q2 的 flow matching 路线；新增 Q4 的分位数/全分布对比；新增 Q5 把 IIA 的方法论贡献升格为独立科学问题。

## 四、研究切入点

切入点 A（对应 Q1/Q5）：度量族几何与协议鲁棒评估。以 IIA 的三族度量与协议矩阵为素材，定义度量族间的映射与一致性条件，产出"协议敏感度画像"，作为方法比较与安全评估的统一语言。现在能做的理由：IIA 已有 13 个检测器、137 组运行与三族对照，理论化只差一步。

切入点 B（对应 Q2）：flow matching 结构一致修复。以因果图正则约束流速度场，得到带逐点不确定性的插补；用"修复后下游检测/预警分数漂移"作为验收。与 SOTA 的差异：现有插补以重构误差为目标，本切入把因果一致性作为可验证约束。

切入点 C（对应 Q4）：基础模型分位数预警。以 TimesFM-3 为底座做零样本多变量预测与 9 分位输出，本地化部署后接共形校准与极值尾部，形成可标定预警。与 SOTA 的差异：把"点预测+固定阈值"升级为"分位预测+事件级标定"，并纳入协议矩阵验收。

切入点 D（对应 Q3）：窗口尺度感知因果 + 流式风险轨迹。用多窗口、多滞后因果识别替换单窗口设定，再以流模型沿学习到的演化场推演风险轨迹。与 SOTA 的差异：GCAD 的失败正说明单窗口因果不可靠，尺度敏感性是必要前提而非附加项。

切入点 E（对应 Q5）：数据版本与可复现性门禁。把 IIA 的逐文件校验、协议矩阵、派生结果表与跨层校验沉淀为可迁移的工程规范，作为方法发布的准入条件。

## 五、对申报材料的反哺建议

1. 立项依据"拟解决的关键科学问题"按 Q1–Q5 重排，把协议鲁棒检测与结构一致修复前置为两大主问题，其余为支撑问题。

2. 研究内容与"关键技术"增补两条生成式路线：修复模块引入 flow matching/随机插值；预警模块引入时序基础模型分位数预测（TimesFM-3 系）并与全分布流路线并列，二者均以协议矩阵验收。

3. 主要参考文献增补：TimesFM-3 官方博客（Google Research, 2026-08）及 HF 权重、Chronos-2、Rectified Flow / Conditional Flow Matching、CSDI/SSSD、GANF、TSB-AD、TAB。

4. 数据情况一节可注明：基础模型路线的训练与验证受非商用许可约束，本地化部署与协议审计可规避数据出域与许可风险。

5. 预期成果增加一项：度量族几何与协议鲁棒评估规范，作为有别于纯模型竞赛的理论产出。
