# 课题申请书草稿

课题名称：时序数据质量检测、智能修复、风险演化建模与动态预警技术研究

## 二、项目简介（不超过 500 字）

时序数据是工业控制、设备监测与安全关键系统的决策基础，其缺失、噪声、异常与漂移会诱导算法误判并放大安全风险。本课题研究检测、修复、建模、预警四位一体的数据驱动方法体系。其一，时序数据质量检测：构建多粒度异常与故障检测模型，对缺失、突变、缓慢漂移等质量缺陷进行在线定位与量化。其二，智能修复：基于生成式与时序扩散模型，在保持因果结构与物理约束的前提下完成缺失填补与异常复原。其三，风险演化建模：融合因果图与时序状态空间模型，刻画风险在多变量间的传播路径与时间演化规律。其四，动态预警：结合极值理论与自适应阈值，实现风险提前预警与不确定性量化。课题以算法安全与可解释性为核心，构建可复现、可审计的基准框架，并在工业报警、设备监测等场景验证，为复杂系统全生命周期数据安全提供关键技术支撑。

## 三、立项依据（约 3000 字）

一、研究背景与意义

时序数据是工业控制、设备监测、能源、金融与安全关键系统的决策基础。然而，感知、通信与存储过程普遍引入缺失、噪声、离群与缓慢漂移等质量缺陷。这些缺陷并不孤立：它们沿"数据—算法—决策"链条逐级传导，劣质输入诱导模型误判，误判在安全关键场景中直接转化为漏报、误报与处置代价。因此，数据质量问题实质上是算法安全问题。

现有研究通常把时序数据处理拆成彼此独立的任务：异常检测回答"是否异常"，缺失填补回答"如何补全"，因果建模回答"变量间关系"，预警回答"何时告警"。这种割裂带来两个系统性后果。其一，各环节方法各自优化局部指标，缺乏端到端的风险可标定性：上游修复是否可信，不以下游预警的稳定性来检验，就无从回答。其二，评估协议本身成为结果的一阶变量。我们在多数据集、多方法的系统对比中发现：同一条预测经"点调整"后 F1 可从 0.006 抬升到 0.697，相差百余倍；同一批预测在两个都被称为"区间/范围"的度量族下可相差 0.53；同一数据集在同一模型下可复现到 0.0001，在另一些方法或切分版本上却显著偏离发表值；个别方法即便使用其官方阈值机制，仍无法复现其发表结果。换言之，文献中的"最高分"经常度量的是协议与段覆盖率，而非检测锐度或真实风险；而"可复现性缺失"本身，就是算法安全层面的薄弱环节。

由此，本课题以"数据质量检测—智能修复—风险演化建模—动态预警"为主线，目标是为复杂系统提供一套端到端、可复现、可审计的数据质量治理与风险预警技术，并把评估严格性确立为算法安全的核心属性。该选题的独特价值在于：不把评测视为方法研究的附属，而是把协议、度量与数据版本治理作为与模型同等重要的研究对象。

二、拟解决的关键科学问题

问题一：质量缺陷的协议鲁棒检测。缺失、突变、漂移在多变量时序中时间—通道耦合，且点级、段级、通道级、系统级的缺陷语义各不相同；如何给出与预警决策代价对齐的度量，解耦"段覆盖"与"检测锐度"，在可标定虚警下实现低虚警定位。

问题二：因果与结构一致的智能修复。填补与复原若破坏变量间的因果结构与物理约束，会制造伪相关、放大下游风险；如何以流匹配、随机插值等现代生成范式完成带不确定性的填补与复原，并以下游检测与预警的稳定性作为修复验收口径。

问题三：尺度感知的多变量风险演化建模。风险沿因果路径传播、随时间演化，且对窗口尺度与采样间隔高度敏感；如何稳定刻画传播路径与演化规律，抑制短窗伪因果与滞后混淆，并回答跨序列依赖能否迁移到风险结构。

问题四：预测不确定性到动态预警的标定。阈值规则（分位数、oracle、极值）与度量族（点级、区间、阈值无关）的选择会显著改变结论；如何在统一"分数—不确定性—决策代价"的框架下，比较分位数预测与全分布流两条概率路线，给出事件级、可标定的动态预警。

问题五：可复现性与数据版本治理。评估协议本身是结果的一阶变量，同名基准掩盖不同的度量族与数据版本；如何给出度量族间的一致性条件与协议矩阵，把可复现性与版本治理确立为算法安全可验证的属性，并作为方法发布的门禁。

三、国内外研究现状及发展趋势

（1）时序异常与质量检测。方法从经典统计与距离模型（PCA、Mahalanobis、隔离森林、OCSVM）发展到深度模型（MSCRED、OmniAnomaly、USAD、Anomaly Transformer、TranAD、DCdetector、TimesNet、iTransformer、CATCH、GCAD 等），精度持续提升，但主流评测长期依赖点调整 F1，其"段覆盖"语义与点级精度差异巨大，且不同论文对同一方法、同一数据集会给出不同的分数与切分统计。近期趋势是把协议与可复现性本身作为研究对象（TSB-AD、TAB 等基准工作），并引入区间/关联类度量与阈值无关指标，逐步承认"评估协议是一阶变量"这一事实。

（2）时序缺失修复。从统计插补、矩阵分解、自编码器发展到生成模型与时序扩散模型（如 CSDI、SSSD 等），代表性工作强调条件生成、多步填补与不确定性估计。当前趋势是引入因果与物理约束，避免"看起来合理"却破坏变量结构的伪修复；但修复质量多以重构误差衡量，鲜少以下游检测与预警的稳定性来检验，这是本课题要填补的缺口。

（3）风险演化建模。因果发现、Granger 因果、图神经网络与状态空间模型被用于刻画变量间的动态关系与传播路径，部分异常检测工作（如 GANF、GCAD）尝试把因果结构作为检测信号。当前趋势是窗口/尺度敏感、可解释、结构稀疏化；难点在于短窗下的伪因果与滞后混淆，以及因果分数本身作为检测信号的稳定性。

（4）动态预警与不确定性。极值理论（POT/SPOT）、自适应阈值与共形预测被用于把分数转为预警，趋势是显式的不确定性量化与事件级评估。现有方法多把预警作为检测的后处理，缺乏"分数—不确定性—决策代价"的统一标定框架。

总体而言，四条线各自演进、缺乏统一的可审计框架；本课题所瞄准的"检测—修复—建模—预警"闭环与协议鲁棒评估，正处于方法交叉点与需求高点。以本团队已有的多数据集、多方法、多度量族对比为经验底座，可以在同一框架内同时推进四个模块，并让每个模块的成果接受可复现性审计。

## 四、研究方案及预期成果（约 3000 字）

一、研究目标

面向时序数据质量缺陷导致的算法安全风险，建立"检测—修复—建模—预警"一体化方法体系与可审计基准，形成可复现、可标定、协议鲁棒的数据质量治理与动态预警技术，并在工业报警与设备监测场景完成验证。围绕前述四个科学问题，分别确立：缺陷检测的协议鲁棒度量、修复的结构一致性保证、风险演化的尺度敏感性、预警的不确定性标定四项目标，并以可复现性作为贯穿四者的约束。

二、研究内容

1. 时序数据质量检测。面向缺失、突变、漂移与异常，建立多粒度（点、段、通道、系统）检测模型；在统一协议矩阵（窗口布局、阈值规则、点调整开关）下开展评测，把"段覆盖"与"检测锐度"解耦，提出与预警决策代价对齐的度量族，并以阈值无关指标（如 AUC 类）作为排序质量的稳定参照。

2. 因果结构一致的智能修复。以流匹配、随机插值与时序扩散等生成式框架为底座，引入因果图与物理约束，建立修复结果的结构一致性度量；研究"修复—检测"闭环互证，即修复质量由下游检测与预警的稳定性来检验，而非仅由重构误差衡量。

3. 风险演化建模。融合因果图与时序状态空间模型，刻画风险在多变量间的传播路径与时间演化；研究窗口尺度感知的因果识别与结构稀疏化，抑制短窗伪因果与滞后混淆，并把演化模型的输出作为检测与预警的先验。

4. 动态预警与不确定性标定。结合极值理论与自适应阈值，把检测分数与预测不确定性共同转化为可标定的预警；比较时序基础模型分位数预测（TimesFM-3 系）与全分布流两条概率路线，研究点级、区间、阈值无关三类度量族间的校准关系与选择准则，形成"分数—不确定性—决策代价"的统一标定框架。

5. 可复现基准与评估审计。建立多数据集、多协议、多度量族的基准框架，输出数据版本治理与复现性审计规范，把"可复现"确立为方法发布的门禁；对每个模块的方法，发布训练配置、阈值规则、切分版本与度量口径，确保结果可被第三方复算。

三、技术路线及可行性分析

路线分五步：基准与数据治理、模块方法研发、模块耦合、场景验证、审计与发布。第一步固定数据载荷与切分版本，建立协议矩阵与三类度量族对照；第二步分别研发检测、修复、演化、预警模块，各自在协议矩阵下消融；第三步以"修复—检测—建模—预警"逐步耦合并做消融，验证结构一致性修复对下游的增益；第四步在工业报警与设备监测场景开展受控验证；第五步发布基准、数据版本规范与审计报告，形成可长期维护的方法库。

可行性来自已有积累：团队已建成多数据集异常检测基准（SWaT、MSL、SMAP、PSM、SMD 及扩展数据集），完成十余种检测器的统一实现与百余组对比实验，覆盖点调整、区间、阈值无关三类度量族，并形成可复现性校验门禁与协议敏感性诊断工具；对极值阈值、因果分数、窗口布局等关键机制均有同口径复现与诊断经验。上述基础设施可直接承载本课题的模块研发与验证，显著降低前期工程成本。技术风险主要集中于耦合建模与因果一致修复，拟以逐步耦合、消融对照与受控场景实验加以控制，并预设替代路线（统计约束退化方案）以保证阶段成果可交付。

四、预期成果

方法与模型：检测、修复、演化、预警模块各若干，含协议鲁棒度量、结构一致修复、尺度敏感因果、不确定性标定等关键组件。基准与规范：可复现基准框架与数据版本治理规范各一套，覆盖多协议与三类度量族。知识产权：发明专利若干；学术论文若干（覆盖检测、修复、演化、预警四个方向）。应用验证：工业报警与设备监测场景验证报告；面向算法安全评估的方法库一套，配套审计报告。

五、关键技术

（1）协议鲁棒的检测评估技术：在同一组预测上并行计算点级、区间、阈值无关三类度量，输出"协议敏感度"画像，供方法选择与安全评估使用。

（2）结构一致的生成式修复：把因果图与物理约束以正则或硬约束形式嵌入流匹配/扩散生成过程，得到带逐点不确定性的填补，并用下游检测与预警的稳定性定义修复验收准则。

（3）尺度感知的风险演化建模：以多窗口、多滞后的因果识别替代单窗口设定，输出带不确定性的传播路径与演化轨迹。

（4）不确定性标定的动态预警：把分数分布、极值尾部与共形覆盖结合，给出可标定的预警阈值与事件级评估。

（5）基础模型分位数预警：以 TimesFM-3 等时序基础模型为底座做零样本多变量预测与多分位输出，本地化部署后接共形校准与极值尾部，形成协议矩阵下的可标定预警。

上述关键技术互为支撑：检测为修复提供验收口径，修复为演化提供干净输入，演化为预警提供风险先验，预警为全链路提供标定终点，由此构成闭环。

（3）风险演化建模基础。团队将图认知推理、认知图谱与事件图谱引入电网主设备诊断与配网决策，承担"基于图认知推理的电网主设备智慧诊断关键技术研究与应用"（国网陕西宝鸡，2023）、"基于认知图谱的电网主设备智慧诊断关键技术研究与应用"（国网福建电科院，2022）、"基于图认知计算的变压器缺陷、故障智慧运检关键技术研究"（国网甘肃电科院，2023）、"基于知识—数据双驱动事件图谱的配网智能决策关键技术研究"（国网福建电科院，2023）等课题；在国家自然科学基金项目"面向可重构电池网络储能系统的动态图学习理论研究"（2021）中积累动态图演化建模能力。同时拥有面向分布式系统的风险评估专利群（基于云重心理论的风险评估、AHP-RBF 风险预测、LSA-GCC 风险识别），以及关系感知动态图注意力网络（PR 2021）、可解释高频金融时序建模（ICDM 2022）等成果，为风险在多变量间的传播与演化建模提供方法基础。

（4）动态预警与预测基础。团队承担"基于大数据分析的电池健康状态和剩余使用寿命预测研究"（国网陕西信通，2021）、"面向电网企业代理购电的复杂因素多时空尺度电力供需预测"（国网河南经研院，2023）、"考虑复杂多因素影响的多时空尺度用电量预测算法研究及应用"（国网陕西营销服务中心，2023）以及基于事件库的电力电量分析预测模型算法研究等课题，在多时空尺度预测、剩余寿命与趋势预警方面具备工程经验；结合极值阈值与不确定性分析的先期研究，可直接支撑动态预警模块。

（5）计算与工程条件。团队建有多层级 GPU 计算集群，并在本地物理隔离环境部署开源大模型，支持数据不出域的研究；已建立"数据集清单—协议矩阵—派生结果表—校验门禁"的工程闭环，代码与数据均按版本管理、支持第三方复算，可保证本课题方法研究从头处于可审计轨道。

3. 数据情况

数据来源：一是公开基准数据，已完成 SWaT、MSL、SMAP、PSM、SMD 五个主流数据集及 UCR、MBA、NAB 等扩展数据集的下载与逐文件校验，部分受控数据（如 WADI、MSDS）按数据方要求申请获取；二是电力行业数据，经多年国网与省公司合作积累，覆盖设备监测、电量负荷、安全日志与运行工况等类型，来源与授权边界明确。

完备度：已核清各公开数据集的规模、异常率、标签粒度与异常段结构，识别出部分数据集在文献间存在切分版本不一致的问题，形成版本治理经验；对缺失与噪声分布亦有初步刻画。行业数据按项目交付物留存，具备多时空尺度的量测与标签。

获取方式：公开下载、官方代码库、按数据方要求申请三类并存。课题组将在执行期内持续扩充受控场景数据，并建立全量数据的版本清单与使用记录，保证下游实验与预警验证可复现。
